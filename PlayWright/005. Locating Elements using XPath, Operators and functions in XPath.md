* Some inportant methods in Xpath

  * contains() = partial ah value match panni call panna. Syntax = //tagName[contains(@class,'value')]
  * start-with() = starting la irukura value ithu la irunthu contain aagi iruntha ithu. Syntax = //tagName[start-with(@class,'value')]
  * text() = text vachi ethana find pananum na ithu use panalam. Syntax =
    * //tagName[text()='text value']
    * //tagName[.'text value'] // using dot
    * //tagName[normalize-space()='text value'] // ithuvum use panalam
  * last() = ithu Xpath la oru list irukku na nama list extract pannalam, specefic ah venum na index number kudukalam athu maari list la last irukurathu extract pananum na ithu use panalam.
  * position() = ithu xpath la irukura list ah index number mention panni extract panna example [position() = 5] ithu maari.
  * Dynamic xpath = ithu oru html 1 ah share panikuthu attributes oda value change aaguthu, elements irukku rendum orey nerathula handle pananum na "Or" use panalam
    * Syntax = //tagName[@id='start' or @id='stop']
