* playwright.config.ts - playwright oda configuration intha tha irukkum ipothaiku chromium, firefox, webkit support pannuthu..
* package.json - ithu java la pom.xml maari inga ithu than

* Ovvoru folder kum nama intha command run pananum apo tha playwright apply aagum
