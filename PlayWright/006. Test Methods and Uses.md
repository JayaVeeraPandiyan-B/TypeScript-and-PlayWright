* COMMON PAGE METHODS

  * Navigation
    * goto() - Open URL
    * reload() - Refresh page
    * goBack() - Back navigation
    * goForward() - Forward navigation
   
  * Locators
    * locator() - Create locator
    * getByRole() - Find by role (best)
    * getByText() - Find by visible text
    * getByLabel() - Find by label
    * getByPlaceholder() - Find by placeholder
    * getByTestId() - getByTestId()
   
  * Actions
    * click() - Click element
    * fill() - Enter text
    * type() - Type slowly (char by char)
    * press() - Keyboard press
    * check() - Select checkbox
    * uncheck() - Unselect checkbox
    * selectOption() - Select dropdown value
   
  * Page Info
    * title() - Get page title
    * url() - Get current URL
    * content() - Get HTML content
   
  * Waits
    * waitForSelector() - Wait for element
    * waitForTimeout() - Hard wait (avoid)
    * waitForLoadState() - Wait for page load
   
  * Tabs / Events
    * on() - Listen events
    * waitForEvent() - Wait for event (popup, download)
   
* LOCATOR METHODS

  * Actions
    * click() - Click element
    * fill() - Enter text
    * clear() - Clear input
    * hover() - Mouse hover
    * focus() - Focus element
   
  * State Check
    * isVisible() - Element visible ah?
    * isEnabled() - Enabled ah?
    * isChecked() - Checkbox checked ah?
   
  * Info
    * textContent() - Get text
    * inputValue() - Get input value
    * getAttribute() - Get attribute
   
* ASSERTION METHODS (EXPECT)

  * Visibility
    * toBeVisible() - Element visible
    * toBeHidden() - Element hidden
   
  * State
    * toBeEnabled() - Enabled
    * toBeDisabled() - Disabled
    * toBeChecked() - Checkbox checked
   
  * Content
    * toHaveText() - Text match
    * toContainText() - Partial text
    * toHaveValue() - Input value match
   
  * Page
    * toHaveURL() - URL match
    * toHaveTitle() - Title match
   
  * Attributes
    * toHaveAttribute() - Attribute check
   
* NETWORK METHODS

    * route() - Intercept request
    * request() - API testing
    * response() - Get response
 
* FILE HANDLING

    * setInputFiles() - Upload file
    * download() - Handle download
 
* DIALOG HANDLING

    * on('dialog') - Listen popup
    * accept() - Accept alert
    * Accept alert - Cancel alert
 
* QUICK SUMMARY

    * Interface = Structure
    * Method = Action
    * Expect = Validation
