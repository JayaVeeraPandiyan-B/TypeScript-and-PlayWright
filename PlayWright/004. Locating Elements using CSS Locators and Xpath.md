* Xpath vida Playwright locators and CSS tha priority because ithu fast ah irukkum, last option tha Xpath

* CSS - Cascading Style Sheets, there are 2 types.

    * Absolute CSS Locators. Stability low - Absolute and relative rendumey combination la use panalam
      * HTML root la irunthu required element varai full path ah kudukanum, ithukku ">" use panuvom, Absolute locators use full DOM path and are fragile.
          * Syntax example = html > body > div:nth-child(2) > div > form > input:nth-child(1)
      
    * Relative CSS Locators. Stability High (Inga Syntax change aagum), whereas relative locators use attributes or partial paths and are more stable and maintainable. Relative mattum tha use pana mudiyum Absolute use pana mudiyathu.
 
      * tag with ID = tag#id(id attribute oda value) ipdiyum call panalam or simple ah #id(id attribute oda value)
      * tag with class = tag.class(class attribute oda value) or .class(class attribute oda value)
      * tag with any other attributes = tag[attribute] or [attribute] 
      * tag with class and attributes = tag.class[attribute] or .class[attribute]
     
      * Inga partial ah kooda call panalam, xpath la ellathukum method irukku but css la ellamey operators tha
     
        * Consider class=main2.
     
        * ^ = ipo partial ah call pananum na "p[class^=ma]" instead of using "p[class='main2']". Ithu value va starting la irunthu match panna.
        * $ = ipo value la endla irunthu partial call pananum na "p[class$='in2']".
        * * = Ipo in between nadula irunthu match panni call pananum na p[class*='ai']
         
      * Ipo continues attributes and value kuduthu kooda match pani call panalam
        * p[id='userID'][class=user] - ithu rendumey match pannum
        * p:not([id='userID'])[class=user] - ithu oru vela first ID match aagala na Class match aagum nu artham. Or use pandra kanaku tha, ethu match aagatho :not([ulla potranum]).
        * p:not([id='userID']):not([class=user]) - ithu opposite ah work aagum ithu rendum ethu match aagaliyo athu suggession kudukum. 
     
* Playwright la intha CSS or Xpath use panni call panna different method irukku, syntax =

    * page.locator("CSS or Xpath locator");
 
* CSS la top to bottom tha possible, bottom to top not possible

* Dynamic elements ah CSS la "tagName[id='start'], tagName[id='stop']" use panuvom inga " , "
