**Annotations irukku**

* Nama oru file ulla evlo test() venalum write panalam athula specefic test mattum run pananum na ".only" annotation kudutha athu mattum run aagum

    * Syntax: test.only();

* List of elements: array la store panni map use panalam

* check panna .check() method irukku

* Assertion method la "not" nu onnu irukku .toBeChecked() method check aagi irukka nu pakum but to be unchecked nu illa so ipo nama "not" use panalam

    * Example: expect(variable).not.toBeChecked();

* Radio Button: circle select any one

    * .toBeVisible(); .toBeEnabled(); athu ennava irukanum nu specefic ah validate panna ".toBe(true or false);"
 
* Checkbox Handling: Check box multiple options select panalam

 Syntaxs: 

**Select a specific checkbox**

</> Markdown
```ts
const sundayCheckbox = page.getByLabel('Sunday'); 
await sundayCheckbox.check(); 
await expect(sundayCheckbox).toBeChecked(); 
```

**Select all checkboxes**

</> Markdown
```ts
const days = ['Sunday', 'Monday', ...]; 
const checkboxes = days.map(day => page.getByLabel(day)); 
for (const checkbox of checkboxes) { 
  await checkbox.check(); 
  await expect(checkbox).toBeChecked(); 
} 
```

**Uncheck last 3 checkboxes**

</> Markdown
```ts
for (const checkbox of checkboxes.slice(-3)) { 
  await checkbox.uncheck(); 
  await expect(checkbox).not.toBeChecked(); 
} 
```

**Toggle checkboxes**

</> Markdown
```ts
for (const checkbox of checkboxes) { 
  if (await checkbox.isChecked()) { 
    await checkbox.uncheck(); 
    await expect(checkbox).not.toBeChecked(); 
  } else { 
    await checkbox.check(); 
    await expect(checkbox).toBeChecked(); 
  } 
} 
```

**Select by specific indexes (e.g. 1, 3, 6)**

</> Markdown
```ts
const indexes = [1, 3, 6]; 
for (const i of indexes) { 
  await checkboxes[i].check(); 
  await expect(checkboxes[i]).toBeChecked(); 
} 
```

**Select checkbox by label name**

</> Markdown
```ts
const weekname = "Friday"; 
for (const label of days) { 
  if (label.toLowerCase() === weekname.toLowerCase()) { 
    const checkbox = page.getByLabel(label); 
    await checkbox.check(); 
    await expect(checkbox).toBeChecked(); 
  } 
} 
```
