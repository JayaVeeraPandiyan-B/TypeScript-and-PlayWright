**Static Dropdown**

* Select la 4 approach use panni acheive panalam by using

    * Visible text
    * Value attribute
    * label
    * index
 
* Dropdown allows users to select options from a list. It can be: 
   • Single-select: Only one item can be chosen (e.g., Country list). 
   • Multi-select: Multiple items can be selected (e.g., Favorite colors).

* Selecting Options from Dropdowns

   * Playwright provides 4 simple ways to select options from a dropdown.

* For Single-select Dropdowns (like #country):

   * By Visible Text: Select "India" by visible label shown to users.
     
</> Markdown
```ts
await page.locator('#country').selectOption('India');
```

   * By Value Attribute: Select option using its value in HTML (e.g., <option value="uk">UK</option>).

</> Markdown
```ts
await page.locator('#country').selectOption({ value: 'uk' });
```

   * By Label: Alternative way to use label property explicitly.

</> Markdown
```ts
await page.locator('#country').selectOption({ label: 'India' });
```

   * By Index: Select option by its position (starting from 0).

</> Markdown
```ts
await page.locator('#country').selectOption({ index: 3 });
```

* For Multi-select Dropdowns (like #colors):

   * Use the same methods, but pass arrays to select multiple options. Example: Select multiple colors using visible text:
 
</> Markdown
```ts
await page.locator('#colors').selectOption(['Red', 'Green', 'Blue']);
```
