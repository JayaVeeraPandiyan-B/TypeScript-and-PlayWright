* Playwright la auto wait and retry-ability built in ah irukku automatic ah wait condition apply aagum.. selenium la nama manual ah wait condition poduvom

* Naama inga priority wise locators methods use panalam

    1. Playwright built in locators
 
        * getByRole() - element oda role (button, link, textbox, .. any interactable element type) base panni find pannum
             * ARIA Role nu onnu irukku athu table la details irukkum athu use panni kooda access panikalam
          
        * getByText() - screen la kaamikkura visible text base panni find pannum, enna tag la venalum irukatum text ah iruntha pothum.
             * Non interactive elements iruntha text ah irukkum apo ithu use panalam.
             * Ithu sub string athavathu partial text kuduthalum ithu work aagum.
             * Suppose case sensitive ah ignore panni kooda validate panalam = getByText(/welcome\s+To+\s+Store/i)
                 * /text/ - ithu ulla tha text podanum
                 * \s - ithu space irukku nu mention panna
                 * i - Case Insensitive nu soldrom (Ignore case sensitive) 
          
        * getByLabel() - form fields ah label text base panni identify pannum, .fill("inputs"); kudutha type pannum antha field la
          
        * getByPlaceholder() - input box oda placeholder text use pannum, place holder attribute oda value use pannalam.
          
        * getByAltText() - image oda 'alt' attribute base panni find pannum, tags like 'img' or 'area' iruntha ithu use panalam
          
        * getByTitle() - element oda title attribute use pannum
          
        * getByTestId() - custom test id (data-testid) use panni element target pannum - attribute maari name "data-testid" nu irukkum athoda value eduthukalam
