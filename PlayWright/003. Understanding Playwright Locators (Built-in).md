* Playwright la auto wait and retry-ability built in ah irukku automatic ah wait condition apply aagum.. selenium la nama manual ah wait condition poduvom

* Naama inga priority wise locators methods use panalam

    1. Playwright built in locators
 
        * getByRole() - element oda role (button, link, textbox, .. any interactable element type) base panni find pannum.
             * ARIA Role nu onnu irukku athu table la details irukkum athu use panni kooda access panikalam.

          </> Markdown
            // Example
            ```HTML
             * HTML {<button>Login</button>}
            ```
          </> Markdown
          ```ts
          PW {page.getByRole('button', { name: 'Login' })}
          ```
          
        * getByText() - screen la kaamikkura visible text base panni find pannum, enna tag la venalum irukatum text ah iruntha pothum.
             * Non interactive elements iruntha text ah irukkum apo ithu use panalam.
             * Ithu sub string athavathu partial text kuduthalum ithu work aagum.
             * Suppose case sensitive ah ignore panni kooda validate panalam = getByText(/welcome\s+To+\s+Store/i)
                 * /text/ - ithu ulla tha text podanum
                 * \s - ithu space irukku nu mention panna
                 * i - Case Insensitive nu soldrom (Ignore case sensitive)
    
            </> Markdown
            ```HTML       
            {<h1>Welcome Back</h1>}
            ```
            </> Markdown
            ```ts      
            {page.getByText('Welcome Back')}
            ```
          
        * getByLabel() - form fields ah label text base panni identify pannum, .fill("inputs"); kudutha type pannum antha field la
          
            </> Markdown
            ```HTML       
            {<label>Email</label> <input type="text" />}
            ```
            </> Markdown
            ```ts      
            {page.getByLabel('Email')}
            ```
          
        * getByPlaceholder() - input box oda placeholder text use pannum, place holder attribute oda value use pannalam.
         
            </> Markdown
            ```HTML       
            {<input type="text" placeholder="Enter email" />}
            ```
            </> Markdown
            ```ts      
            {page.getByPlaceholder('Enter email')}
            ```
          
        * getByAltText() - image oda 'alt' attribute base panni find pannum, tags like 'img' or 'area' iruntha ithu use panalam
         
            </> Markdown
            ```HTML       
            {<img src="profile.png" alt="profile image" />}
            ```
            </> Markdown
            ```ts      
            {page.getByAltText('profile image')}
            ```
          
        * getByTitle() - element oda title attribute use pannum
         
            </> Markdown
            ```HTML       
            {<button title="Close">X</button>}
            ```
            </> Markdown
            ```ts      
            {page.getByTitle('Close')}
            ```
          
        * getByTestId() - custom test id (data-testid) use panni element target pannum - attribute maari name "data-testid" nu irukkum athoda value eduthukalam
         
            </> Markdown
            ```HTML       
            {<button data-testid="submit-btn">Submit</button>}
            ```
            </> Markdown
            ```ts      
            {page.getByTestId('submit-btn')}
            ```
 
    2. CSS Selectors - Use locator();

            </> Markdown
            ```HTML
            <button id="login-btn" class="btn primary">Login</button>
            ```

            </> Markdown
            ```ts
            page.locator('#login-btn')          // id
            page.locator('.btn.primary')        // class
            ```
 
    3. Xpath - Use locator();  page.locator('//button[text()="Login"]') // XPath

  * Playwright.config.ts file ulla namaku thevaiku etha maari configure kooda panikalam
 
  * To handle dynamic elements example = page.getByRole('button', {name: /START|STOP/}); By using " | " operator.
 
* **List of common HTML elements and their corresponding ARIA roles**

*    a href="..." - link 
*    area href="..." - link 
*    button - button 
*    form (with name attribute) - form 
*    h1, h2, h3, h4, h5, h6 heading 
*    header - banner (context-specific) 
*    img (with alt) - img 
*    input type="button" - button 
*    input type="checkbox" - checkbox 
*    input type="email" - textbox 
*    input type="password" - textbox 
*    input type="radio" - radio 
*    input type="range" - slider 
*    input type="reset" - button 
*    input type="search" - searchbox 
*    input type="submit" - button 
*    input type="text" - textbox 
*    li - listitem 
*    ol, ul - list 
*    option - option 
*    select - listbox (or combobox, depends on usage) 
*    table - table 
*    tbody, thead, tfoot - rowgroup 
*    td - cell 
*    th - columnheader or rowheader 
*    textarea - textbox 
*    tr - row
