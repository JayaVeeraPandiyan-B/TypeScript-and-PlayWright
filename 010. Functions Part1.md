  function ah call pannum pothu "methodName()" or "methodName();" ipdi tha kupdanum

* Methods = ithu OOPS related nama oru method ah class la create panna athu "Methods"

```ts

function test_01():void {
    console.log("Function example");
}

test_01();

// *****************************************************************************

    return (x*y);
}

console.log("Number function output type 2:",test_02(5,5)); // Type 2
```     

* Rest Parameters nu irukku - ithu unlimited datas or data types store panikalam "," pottaa limit irukku but limit ah illama evlo parameters venalum pass panalam, ithu ellathaiyum Array va store panikum

  Syntax: **single data type**

</> Markdown

```ts

            function functionName(...variableName:Data Type[]):void
            {
                //Statements blocks of code
            }

// *****************************************************************************

function addNumber(...num:number[])    {

    let i;
    let sum:number = 0;

    for (i=0; i<num.length; i++){sum = sum + num[i];}
    console.log("Addition of given numbers is:",sum);
}

addNumber(1,2,2,2,3);

```

* **Optional Parameters** nu irukku - function ulla multiple parameters declare panum pothu sila parameters mattum pass pani enna pass panomo athu muttum function la execute aagum, entha variable and type set uh optional ah venumo "?" pota pothum, exception error ethum varathu

  Syntax:
</> Markdown
```ts
            function functionName(variableName:DataType, variableName:DataType, variableName?:DataType):void
            {
                //Statements
            }

//*****************************************************************************

function optionalFunction(x:number, y:string, z?:number)
{
    console.log("X value is:",x);
    console.log("y value is:",y);
    if (z !== undefined){console.log("z value is:",z);}
}

optionalFunction(2000105128, "Jaya Veera Pandiyan B");

```

* Named function with **default parameter** - Ipo oru function parameter la ethummey nama pass panalama na default value kooda assign panalam athu aparam ah user kudukura value - default value va reassign panidum. Athukku function bracket ullaye variable ku value assign panidanum.

  Syntax:
</> Markdown
```ts

           function functionName(variableName:DataType, variableName:DataType = 0):void
            {
                //Statements
            }

//*****************************************************************************

function namedFunction(x:number, y:number=0)
{
    let discount:number = x*y;
    console.log("Discount amount is:",discount);
}

namedFunction(100);
namedFunction(100,2);

```
