Conditional Statement: Oru group of statement ah condition potu use panna, iru epovum Ture or False ah tha decide pannum.. intha condition true ah iruntha block of code run aagum, false ah iruntha skip panni next statement or block of code ku pogum

Java la irukura if - else tha

* "if" false na "else if" ithuvum false na continues "else if" ella condition um false na last ah vera vazhi illama "else" nadula "else if" ethana true na angaye execution mudinjidum.

* "if, else if, else" inga la nama Condition kudupom but "switch = expression" kudupom, because condition epovum true or false tha return pannum but switch la case kudupom inga true or false illama enna vena return pannum

* break = oru statement ah stop pannum, continue = oru statement ah skip pannum.

Key Points

  • if → Executes code if condition is true. 
  • if-else → Executes one block for true, another for false. 
  • if-else-if → Checks multiple conditions sequentially. 
  • switch-case → Compares a value against multiple cases for efficiency.
