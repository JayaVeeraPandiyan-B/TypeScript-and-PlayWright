JavaScript is not type safety

TypeScript is type safety

JavaScript la data types automatic ah decide panikum but TypeScript la data types nama explicit ah kudukalam or optional

we can diffrentiate by - TS(Static) na oru variable ku value initialize panita same variable ku vera data initialize pana mudiyathu, but JS(Dynamic) ku panalam.

  1. Compile time error we can see this in TS
  2. No visible error in JS

**Update **- Ippo nama data type vachi TypeScript file ah node la run panna execute aaguthu

  1. Value initialize panna variable ku redeclare pana mudiyala in TS but run aaguthu
  2. nama TypeScript la data type ah mention pananum illana JavaScript ah run aagum

* Type/DataType: TypeScript la Data type ah Type nu kooda sollalam. Ithula "number" tha data type

* Annotation: epolam nama explicit ah data type ah oru variable ku apply pandromo athu tha annotation. Ithula ": number" tha annotation.

Data types = Primitive data types(Built in) and Non primitive data types

Primitive Data Types = Single value the store pana mudiyum

* **Number** = numeric values, decimals, big numbers
</> Markdown
```ts
let age : number = 30
let price = 52.78
let big = 123456789123

console.log("Age:", age)
console.log("Price:", price)
console.log("Big:", big)
```
* **String** = 3 different ways la nama String declare panalam - ' '(Single quote), " "(Double quotes) and ``(Back lit). ithula ``(Back lit) la String kooda data or parameter pass pananum na ithu use panalam, example "let name : string = `Hello ${Jaya}`"

</> Markdown
```ts
let age : number = 30
let price = 52.78
let big = 123456789123

console.log("Age:", age)
console.log("Price:", price)
console.log("Big:", big)
```
       
* **Boolean** = Only 2 values either "True" or "False"
</> Markdown
```ts
let isStudent : boolean = true
let isMarried : boolean = false

console.log('Is Student:', isStudent)
console.log("Is Married:", isMarried)
```
* **Null** = Ithu TypeScript ku mattum tha irukku, null & undefined rendumey similar tha but different, nama variable ku entha value um kudukala na "null" use panalam.. ithu thevai illathathu than 
</> Markdown
```ts
let emptyValue : null = null
let notAssigned : undefined = undefined

console.log(emptyValue, notAssigned)
```
* **Undefined** = Ithuvum same as null, TypeScript some case la ithu rendum thevaiku etha maari return pannum
  
* **Any** = TypeScript oda special type, ithu careful ah use pananum because ithu TypeScript benefit ah voilate panni loose pana koodum - epdi na any type use pani value ah variable ku declare panna antha data type value ah enna venalum store panikalam compile error eh varathu.
</> Markdown
```ts
let value : any = "Hello"
console.log(typeof value)
value = 100
console.log(typeof value)
value = true
console.log(typeof value)

console.log('Final Value:',value)
```
* **Union Type** = Ithu explicit ah mention pandra type illa, pala data types ah orey variable ku store panalam example "let id : number | String | boolean" ipo ithukku thani thaniya variable initialize panalam, epdi pathalum entha value final ah initilize pandromo athuthan. 
</> Markdown
```ts
let id : number | String | boolean

id = true; id = "Jaya"; id = 2000105128

console.log(id)
```
* **Void** = Ithu functions ku tha use panuvom variables ku illa, a group of statement which perform certain task(like Java method), ipo oru function ethum return pana porathu illana "void" nu kudupom but inga konjam syntax different uh "function sun():void {}" nu kudupom but kudukanum num avasiymum illa.
</> Markdown
```ts
function show():void
{
    console.log("Welcome")
}
show()
```
