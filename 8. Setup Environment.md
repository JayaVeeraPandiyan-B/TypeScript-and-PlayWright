Required for environment Setup

1. nvm
   
2. Node - Run Time Environment -> Download from Node website
   
3. TypeScript Compiler - It'll compile the TypeScrippt code and convert into JavaScript
   * To install -> Open CMD Promt -> type **"npm install -g typescript"** -> Press Enter
     
4. VS Code editor - Best for MS related languages lot of extentions and more..

Once every successfull installation VS Code open panni nama ".ts" nu file name kudutha tha athu enna file nu declare pannamudiyum -> ".ts" means TypeScript

nama TypeScript ku VS code la eluthura code compile pani tha execute pana mudiyum, so athukku

Code eluthuna apram VS top la "Terminal" click pannu -> New Terminal -> type -> **tsc "Sub folder name"\"file name with extention"** -> Enter (Short cut = Ctrl + ~)
   Example: tsc Day1\FirstDemo.ts  ------> Ipdi tha basic/Initial ah compile panamudiyum

---------------------------------- Ippo Direct ah TypeScript ah Execute pandratha epdi ----------------------------------

Ithu tha real life process

5. TypeScript Executor - Ithu additional package ts file ah compile panni run panama direct ah ts file ah run pandrathukku so js file ah la convert aagathu direct ah ts ah run aagum

   Athuku "VS Terminal" or "CMD Promt" la kooda install panikalam, ipdi tha pana mudiyum UI moolama download panni install pana mudiyathu  

   Intha prompt kudutha install aagidum = **"npm install -g tsx"**

So inimey nama TypeScript file ah execute pandrathukku **tsx "Sub folder name"\"file name with extention"** ipdi kudutha execute aagidum
   Example: tsx Day1\FirstDemo.ts

* To check version -> Open CMD Promt -> nvm -v (or) nvm --version - (Node Version Manager)
* To check version -> Open CMD Promt -> node -v (or) node --version - (Node.js)
* To check version -> Open CMD Promt -> npm -v (or) npm --version - (Node Package Manager)
* To check version -> Open CMD Promt -> tsc -v (or) tsc --version - (TypeScript Compiler)
* To check version -> Open CMD Promt -> tsx -v (or) tsx --version - (TypeScript Executor)
