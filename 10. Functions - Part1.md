**Difference between Functions & Class**

* Functions = nama Object or class illama create panalam (Other programmming language la SubRoutine nu soluvanga)

  function ah call pannum pothu "methodName()" or "methodName();" ipdi tha kupdanum

* Methods = ithu OOPS related nama oru method ah class la create panna athu "Methods"

* Rest Parameters nu irukku - ithu unlimited datas or data types store panikalam "," pottaa limit irukku but limit ah illama evlo parameters venalum pass panalam, ithu ellathaiyum Array va store panikum

  Syntax: **single data type**

            function functionName(...variableName:Data Type[])
            {
                //Statements blocks of code
            }

  Syntax: **Multiple data types**

            function functionName(...variableName:(string | number)[]):number
            {
                //Statements blocks of code
            }

* Optional Parameters nu irukku - function ulla multiple parameters declare panum pothu sila parameters mattum pass pani enna pass panomo athu muttum function la execute aagum

  Syntax:

            function functionName(variableName:DataType, variableName:DataType, variableName:DataType)
            {
                //Statements
            }
