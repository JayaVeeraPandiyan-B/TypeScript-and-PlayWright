* **Interface**

  * object structure define panna use pannura blueprint - object epdi irukanum nu rule define pannurathu

  * Nama enna rule potu create pandromo ithu apply pannanum illana error varum, but athu interface liye "?" optional nu kudutha error varathu

  * Simple - Interface = blueprint and Class/Object = building. Example: Blueprint → 3 rooms, 2 doors irukkuna House → must follow blueprint

  * Class vs Interface,

    * Class - Class la properties -> constructor -> Methods
    * Interface - properties -> Methods antha methods um Abstract methods ah irukkum (Only methods signature no implementation)
   
  * Development ithu mostly use aagum

* **Example: 1 - Basic Interface**

</> TypeScript
```ts
interface person   {

    name:string;
    age:number;

}

let student : person  =  {

    name : "Jaya Veera Pandiyan B",
    age : 34

}

console.log(student.name);
console.log(student.age);

// Output

Jaya Veera Pandiyan B
34
```

* **Example: 2 - Optional Property** - optional nu kudutha nama assign pananum nu avasiyam illa apdi assign panama use panna undefined nu vanthudum

</> TypeScript
```ts
interface employee {

    empID : number;
    empName : string;
    empDepartment ? : string;

}

//Using optional
let empInfo : employee = {

empID : 2000105128,
empName : "Jaya Veera Pandiyan B"

}

//Using full Interface

let empInfo1 : employee = {

    empID : 707053,
    empName : "Jaya Veera Pandiyan B",
    empDepartment : "HealthCare"

}

console.log("Using optional", empInfo.empDepartment);
console.log("Using full Interface", empInfo1.empDepartment);

// Output

Using optional undefined
Using full Interface HealthCare
```

* **Example: 3 - Readonly Property** - Read-Only property once assign panina change pana mudiyathu try panna error varum, 

</> TypeScript
```ts
interface employee {

   readonly empID : number;
    empName : string;

    displayEMP ? () : void ;

}

let empInfo2 : employee = {

    empID : 2000105128,
    empName : "Jaya Veera Pandiyan B",

    displayEMP() {
        console.log(`Employee ID: ${this.empID} and Employee Name: ${this.empName}`); // Using this keyword to Implementing the interface by Object
        console.log(`Employee ID: ${empInfo2.empID} and Employee Name: ${empInfo2.empName}`); // Using class name to Implementing the interface by Object
    }

}

empInfo2.displayEMP?.();

**empInfo2.empID = 2000; // Cannot assign to 'empID' because it is a read-only property.**

// Output

Employee ID: 2000105128 and Employee Name: Jaya Veera Pandiyan B
Employee ID: 2000105128 and Employee Name: Jaya Veera Pandiyan B
```
