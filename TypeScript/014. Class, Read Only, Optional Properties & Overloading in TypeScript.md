* **Class Structure**

* TypeScript la class create pananum na "class" keyword use pananum, class name "Pascal" Upper case la tha start pannanum athu tha standard

* Oru class na - Class, Conctructor and method combination irukanum

* TypeScript la Object create pananum na class venum

* Structure -> Class (Constructor -> Method) -> (outside the calss) "Object" -> Execution

    * class - variable declare pandrathukku
    * constructor - this keyword use panni parameter la irukura variable class variable ku ethuku ethunu assign pandrathukku, Constructor eppovum invoke aagidum.
    * method - namakku enna maathiri intha code venum/enna pannanum nu logic elutha
    * Object - outside tha class argument pass panna
    * Execution - objectName.method() ipdi potu use panna tha execution nadakum

Example:
</> TypeScript
```ts
//Class
class Student   {
    readonly studentID:number;
    name : string;
    email? : string;
    //schoolName : string;

// Constructor
constructor (id:number, name:string, email?:string)  {
    this.studentID=id;
    this.name=name;
    this.email=email; // email pass panala na ithu undefined
}

//Method
displayInfo() : void    {

    console.log("Student id is:",this.studentID);
    console.log("Student name is:",this.name);

    if(this.email)    {
        console.log("Email id is:", this.email);
    } else  {
        console.log("Oops - Email id not provided!!");
    }
}

}

//Object

let obj1 = new Student(2000105128, "Jaya Veera Pandiyan B");
let obj2 = new Student(200010512, "Jaya Veera Pandiyan B", "jayaveerapandiyanb@gmail.com");

//Execution
console.log("Object 1 with optional email");
obj1.displayInfo();
console.log();
console.log("Object 2 with email");
obj2.displayInfo();

// Output
Object 1 with optional email
Student id is: 2000105128
Student name is: Jaya Veera Pandiyan B   
Oops - Email id not provided!!

Object 2 with email
Student id is: 200010512
Student name is: Jaya Veera Pandiyan B   
Email id is: jayaveerapandiyanb@gmail.com
```

* **Constructor and Method Overloading**

*  Constructor overloadind

Example:
</> TypeScript
```ts
class calculator {

    constructor();  // Default constructor
    constructor(a:number, b:number); // Parameterized constructor

    constructor(a?:number, b?:number)   {   // /*Implementation*/

        if (a !== undefined && b !== undefined)   {
            console.log("Sum of a & b is:", (a+b));
        } else  {
            console.log("default constructor execute!!");
        }

    }

}

let obj3 = new calculator(); // Default constructor call

let obj4 = new calculator(5,2); // Parameterized constructor

// Output

default constructor execute!!
Sum of a & b is: 7
```

* Method Overloading

Example:
</> TypeScript
```ts
class calculator {

    add(a:number, b:number):number;
    add(a:number, b:number, c:number):number;

    add(a:number, b:number, c?:number):number   {
            if(c !== undefined)    {
                return (a+b+c);
            }
            return (a+b);
    }

}

let obj5 = new calculator();
console.log("First method",obj5.add(2,3));
console.log("Second method",obj5.add(2,3,5));

// Output
First method 5
Second method 10
```
