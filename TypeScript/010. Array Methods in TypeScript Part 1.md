* push() - Already oru array irukku but additional elements add pananum na "push()" function use pananum, ithu array length theriyala but array oda last la new elements add pananum na intha function use pananum
  
    * Syntax =
        * arrayVariable.push(element,.....,element);

* pop() - Remove the last single element in Array

    * Syntax =
        * arrayVariable.pop(); // remove last single element
          
        * let variable = arrayVariable.pop(); // to know what last element removed

* shift() - Remove the first single element in Array

    * Syntax =
        * arrayVariable.shift(); // remove first single element
          
        * let variable = arrayVariable.shift(); // to know what last element removed

* unshift() - ithu push() method ku opposite, array oda first(starting) la element add pannum

    * Syntax =
        * arrayVariable.unshift("argument",...); // add elements in the begining of the array.

* concat() - combine 2 or more arrays, existing array ah impact panama new variable la store pananum, existing and concated array combine aagidum. existing thaniya irukkum.

    * Syntax =
        * let concatedVariable = arrayVariable.concat([1], [2, 3]);

* slice() - Ithu array oda oru section ah extract pannum, array index number ah sonna example: 1 - 3 nu sonna array la irukura 0, 1, 2 index ah extract pannum

    * Syntax =
        * let sclicedVariable = arrayVariable.slice(1, 3); // existing array ah impact panathu.

* splice() - Add/Remove the element from a array anywhere not in front or end we can perform anywhere, ithu original array eh impact pannum

    * Syntax =
        * let splicedVariable = arrayVariable.splice(1, 3); // ithu array index la irukura 1, 2, 3 elements ah remove panidum, argument la irukura 1 starting index number of the array and 3 vanthu elvo count ah delete pananum kudukurathu, nama 1, 3 nu kuduthanaala Array la 1st index la irukurathula irunthu 3 index values ah remove pannu nu meaning
     
        * let splicedVariable = arrayVariable.splice(0, 0, 'Apple', 'Mango', 'Banana'); // ithu starting count 0 and second 0 meaning don't remove apparam 'Apple', 'Mango', 'Banana' from the 0th index la irunthu intha 3 value ah element ah add pannu nu meaning.
     
        * let splicedVariable = arrayVariable.splice(1, 3, 'Apple', 'Mango', 'Banana'); // ithu existing array la irukura 1st index ah serthu next 2 index la values ah remove panitu 'Apple', 'Mango', 'Banana' values ah add panidum.
     
* indexOf(String value) - ithu index ulla value kudutha antha value enna index number la iruku nu number ah return pannum, suppose nama kudukura value array la illana "-1" nu return pannum

    * Syntax =
       * let indexOfBanana = arrayVariable.indexOf("Banana"); // 2 nu return pannum.
 
       * let indexOfPapaya = arrayVariable.indexOf("Papaya"); // Papaya array la illa na ithukku -1 nu return pannum error ethum varathu.
 
       * let indexOfGraps = arrayVariable.indexOf("Graps", 2); // ithu last la nama enna index number kudukuromo athula irunthu intha element ah search pannum.
      
       * let indexOfGraps = arrayVariable.indexOf("Graps", 4);" // suppose ipdi kudukurom graps 3rd index la irukku but ithu 4th index la irunthu search pannum so namaku -1 nu return pannum.

* includes() - nama kudukura string element value array la iruka nu check pannum, iruntha true illana false return pannum

    * Syntax =
       * let checkInclude = numb.includes(10); ithu numb array la intha value iruntha true illana false
     
* toString() - ithu array la irukura values ah string ah convert pana use aaguthu

    * Syntax =
       * arrayVariable.toString(); // Suppose array value "[ 1, 2, 3, 4, 5 ]" ipdi iruku na "1,2,3,4,5" normal string ah convert panidum. itha variable liyum store panalam straight ah kooda use panalam
