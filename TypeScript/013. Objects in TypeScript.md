* Object - it is a group of variables and methods in programming language concept, another words objects is a collection of key and value phase

    * TypeScript la Object na key–value pair la data store panna use pannura structure.
          * Simple ah sonna: Object = properties (keys) + values

    * Properties means variables
    * Behaviour means methods

* There are different ways to create an object in JS/TS,

    * Using object type - directly define the value for variable (JS/TS)
    * Inline type object - we also define the datatype of the keys (TS)
    * Using the aliases (JS/TS)
    * Using the Classes (JS - ES16/TS)
 
* **Using Object type**

The TypeScript 'Object' type represent all the values which are non primitive

Basic Example:
</> TypeScript
```ts
let person = {
    name : "Jaya Veera Pandiyan B",
    age : 34,
    city : "Chennai"
};

console.log(person);
console.log("Employee name:",person.name);
console.log("Employee age:",person.age);
console.log("Employee city:",person.city);
```

* **function in Object**

Oru object ulla function kooda pass panalam

Object la oru function irukku antha function ulla object oda variable vachi value venum na "this.objectVariableName" koota varum

Example
</> TypeScript
```ts
let person = {
    name : "Jaya Veera Pandiyan B",
    age : 34,
    wlcm : "Hello da!!",
    greet : function () : string {
        return `${this.wlcm}`;
    }
};

console.log(person.name);
console.log(person.age);
console.log(person.greet()); // Easy
```

* **Modifying the existing object value**

Example
</> TypeScript
```ts
let person = {
    name : "Jaya Veera Pandiyan B",
    role : "Engineer"
};

console.log("Original value is:", person.role);
person.role = "Manager";
console.log("After modification value is:", person.role);
```
