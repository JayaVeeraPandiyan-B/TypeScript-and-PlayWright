* **Inheritance**
* Inheritance is basically about reusability of properties/methods from parent-child class, we dont need to rewrite we can simply inherit from another class - giver is Parent and receiver is child

  * Parent/Super/Base class
  * Child/Sub/Derived Class
 
* Oru child class parents class la irunthu properties and methods derive pana poguthu na "extends" keyword use pananum

   * Example:
 
      class A {};
      class B exyends A {};

* So ippo rendu class liyum constructor irukkum child class la super class properties varanum na "super" keyword use panni properties declare pananumm, super class parameters ah child class parameters oda join panitu super(propertyName).

Example:

</> TypeScript
```ts
// Inheritance Concept

class car {

    name : string;
    colour : string;
    model : string;

    constructor (name:string, colour:string, model:string)  {
            this.name = name;
            this.colour = colour;
            this.model = model;
    }

    start(): void {
        console.log("Car started...!");
    }

    stop(): void {
        console.log("Car stoped...!");
    }

}

class rangeRover extends car {

    year : number;

    constructor(name:string, colour:string, model:string, year:number)   {
        super(name, colour, model);
        this.year = year;
    }

    start(): void {
        console.log("Range Rover starter ... !");
    }

    stop(): void {
        console.log("Range Rover stoped ... !");
    }

    rryom(): void {
        console.log(`Car name: ${this.name} Colour: ${this.colour} model: ${this.model} and model: ${this.year}`);
    }

}

let carVar = new rangeRover("Range Rover", "Black", "Discovery", 2025);
carVar.rryom();

let carVar1 : car = new rangeRover("Range Rover", "Black", "Discovery", 2025);
carVar1.start();
carVar1.stop();

// Output

Car name: Range Rover Colour: Black model: Discovery and model: 2025
Range Rover starter ... !
Range Rover stoped ... !

``` 

* **Overloading** → Same method + different parameters

* **Overriding** → Parent method change in child class (Same method, same parameter, only logic different super class method oda structure change aagathu)

* **Super() and super** - Java la ithu variable ah kooda invoke panalam but JS/TS la ithu panna mudiyathu athutha inga limitation

   * Super() - Parent class constructor ah immediate ah invoke pandrathukku intha method use aaguthu

   * super - ithu parent class method ah invoke pandrathukku use aaguthu
 
**Example:**

</> TypeScript
```ts
// Super keyword and method demo

class Supernum {

num1 : number = 10;

constructor ()  {
    console.log("This is Super class Constructor");
}

    display()   {
    console.log("This is super class display Method");
}

}

class childNum extends Supernum{

    num1 : number = 20;

    constructor()   {
        super(); // Ithu super class oda properties ah invoke pannum ithu super method
        console.log("This is child class constructor");
    }

    show()  {
        console.log("Child class show method");
    }

    display()   {
        super.display(); // Ithu super class method ah invoke pannum ithu super keyword.
        console.log("This is child class display Method");
    }

}

let superDemo = new childNum();

superDemo.show();
superDemo.display();
```
