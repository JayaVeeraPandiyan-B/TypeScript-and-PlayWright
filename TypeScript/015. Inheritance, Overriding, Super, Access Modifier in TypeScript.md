
* Inheritance is basically about reusability of properties/methods from parent-child class, we dont need to rewrite we can simply inherit from another class - giver is Parent and receiver is child

  * Parent/Super/Base class
  * Child/Sub/Derived Class
 
* Oru child class parents class la irunthu properties and methods derive pana poguthu na "extends" keyword use pananum

   * Example:
 
      class A {};
      class B exyends A {};

* So ippo rendu class liyum constructor irukkum child class la super class properties varanum na "super" keyword use panni properties declare pananumm, super class parameters ah child class parameters oda join panitu super(propertyName).

Example:

</> TypeScript
```ts
class car {

    name : string;
    colour : string;
    model : string;

    constructor (name:string, colour:string, model:string)  {
            this.name = name;
            this.colour = colour;
            this.model = model;
    }

    start() {
        console.log("Car started...!");
    }

    stop()  {
        console.log("Car stoped...!");
    }

}

class rangeRover extends car {

    year : number;

    constructor(name:string, colour:string, model:string, year:number)   { // Constructor parameter ipdi kondu varanum
        super(name, colour, model); // Ipdi kondu varanum super key ku
        this.year = year;
    }

}
``` 

* Overloading → Same method + different parameters

* Overriding → Parent method change in child class (Same method, same parameter, only logic different super class method oda structure change aagathu)
