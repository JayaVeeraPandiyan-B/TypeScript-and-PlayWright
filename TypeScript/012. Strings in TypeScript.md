String - It is a Text value or a combination of characters

* Single Quote - String literal ('Single quote')
* Double Quote - String literal ('Double Quote')
* Backtick - String template, Variables / expressions string ulla insert panna use pannuvom.
  
    * Backtick benefits = 
      1. Variable interpolation (Oru string value ulla another string variable ah insert pani use panalam) ex: 'Hello ${variable contains value}, Good day!!'  
      2. Multiline strings
      3. Readability improve

String methods:

1. length - ithu oru string la irukura character values evlo irukku nu count pannum space iruntha athayum serthu count pannum.
  
</> TypeScript
```ts
let nme : string = "Jaya Veera Pandiyan B";
let nmeLength = nme.length;
console.log("String character count is:", nmeLength); // String character count is: 21
```

2. toLowerCase() - Ithu oru string value va lower case la mathum

</> TypeScript
```ts
let nme : string = "Jaya Veera Pandiyan B";
let nmeLength = nme.toLowerCase();
console.log(nmeLength); // jaya veera pandiyan b
```

3. toUpperCase() - Ithu oru string value va upper case la mathum

</> TypeScript
```ts
let nme : string = "Jaya Veera Pandiyan B";
let nmeLength = nme.toUpperCase();
console.log(nmeLength); // JAYA VEERA PANDIYAN B
```

4. charAt() - intha method nama enna index number kudukuromo string value index la place aagi irukura character ah eduthu kudukum

</> TypeScript
```ts
let nme : string = "Jaya Veera Pandiyan B";
let nmeLength = nme.charAt(3);
console.log("3rd index character is:",nmeLength); // 3rd index character is: a
```

5. indexOf("char") - quotes ulla enna character kudukuromo athu enna index la irukku nu number sollum.

</> TypeScript
```ts
let nme : string = "Jaya Veera Pandiyan B";
let nmeLength = nme.indexOf("r");
console.log("Index number of 'r' is:",nmeLength); // Index number of 'r' is: 8
```

6. substring() - ithu combination of string value irukku na athukulla ethula irunthu ethu varai venum nu pick panni kondu varum nama kudukura value poruthu

    * method workflow substring(starting index (Index based starts from 0), ending index "Not a index based starts from 1 it is exclusive")

</> TypeScript
```ts
let nme : string = "Jaya Veera Pandiyan B";
let nmeLength = nme.substring(0, 4);
console.log("Sub string is:",nmeLength); // Sub string is: Jaya
```

7. includes() - ithu nama enna value kudukuromo oru string ulla antha value include aagi iruka nu check pannum iruntha true illana false nu boolean return pannum

</> TypeScript
```ts
Ex: 1
let nme : string = "Jaya Veera Pandiyan B";
let res = nme.includes("Veera");
console.log("'Veera' include?:",res); // 'Veera' include?: true

Ex: 2
let nme : string = "Jaya Veera Pandiyan B";
let res = nme.includes("Babu");
console.log("'Veera' include?:",res); // 'Veera' include?: false
```

8. startsWith(" ") - Ithu nama enna word kudukuromo antha string value athula irunthu tha start aagutha nu check pannum, boolean return pannum

</> TypeScript
```ts
Ex: 1
let nme : string = "Jaya Veera Pandiyan B";
let res = nme.startsWith("Jaya");
console.log("Start with 'Jaya'?:",res); // Start with 'Jaya'?: true

Ex: 2
let nme : string = "Jaya Veera Pandiyan B";
let res = nme.startsWith("Veera");
console.log("Starts with 'Veera'?:",res); // Starts with 'Veera'?: false
```

9. endsWith(" ") - Ithu nama enna word kudukuromo antha string oda end value ah irukka nu check pannum, boolean return pannum

</> TypeScript
```ts
Ex: 1
let nme : string = "Jaya Veera Pandiyan B";
let res = nme.endsWith("B");
console.log("ends with 'B'?:",res); // ends with 'B'?: true

Ex: 2
let nme : string = "Jaya Veera Pandiyan B";
let res = nme.endsWith("Jaya");
console.log("ends with 'Jaya'?:",res); // ends with 'Jaya'?: false
```

10. replace(" ", " ") - Oru string la irukura value words or characters replace panalam, ithu original value va impact panathu..

    * Syntax = replace("Existing value", "New value")
   
</> TypeScript
```ts
let nme : string = "Jaya Veera Pandiyan B";
let res = nme.replace("B","Babu");
console.log("Replaced string is:",res); // Replaced string is: Jaya Veera Pandiyan Babu
```
