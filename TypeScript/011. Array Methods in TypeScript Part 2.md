**Important functions **

* forEach() - every array element ku function ah oru time execute pannum, ithu oru function ah ey parameter ah eduthukum

    * Syntax = arrayVariable.forEach(function(currentValue, index, array) {  })
 
    * currentValue - The current element being processed in the array
    * index(Optional) - The index of the current element being processed in the array
    * array(Optional) - The array the current element belongs to.
 
Example: 1 - General loop condition

1) Using General loop condition

</> Markdown
``` ts
let fruits : string[] = ['Apple', 'Banana', 'Grapes', 'Dragon fruit', 'Jackfruit'];

for (let i in fruits)  {
  console.log(i, "=",fruits[i]);
}
```
2) Using for each condition

</> Markdown
```ts
let fruits : string[] = ['Apple', 'Banana', 'Grapes', 'Dragon fruit', 'Jackfruit'];

fruits.forEach(function(element, index)  {
  
  console.log(`${index}`, `${element}`);
  
})
```
