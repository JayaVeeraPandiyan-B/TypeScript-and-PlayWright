
# JAVA – CORE CONCEPTS INTERVIEW ANSWERS

1. Explain Object-Oriented Programming (OOPs) concepts with real-world examples.

  * OOPs is a programming approach based on objects and classes.

    * **Main OOP concepts:**

      * **Encapsulation:** Binding data and methods together.

        * Example: ATM machine hides internal processing and only exposes required operations.


      * **Inheritance:** One class acquires properties of another class.

        * Example: Dog inherits Animal properties.


      * **Polymorphism:** One action behaves differently in different situations.

        * Example: Same payment method behaves differently for UPI, Card, or Net Banking.


      * **Abstraction**: Hiding implementation details and showing only functionality.

        * Example: Car driver uses steering and brake without knowing engine internals.


2. What is the difference between a class and an object?

| Class              | Object                 |
| ------------------ | ---------------------- |
| Blueprint/template | Real instance of class |
| Logical entity     | Physical entity        |
| Example: Car       | Example: BMW car       |

Example:

```java
class Car {
   String color;
}

Car c = new Car();
```

Here:

* `Car` → Class
* `c` → Object

3. What is inheritance? Explain different types of inheritance in Java.

  * Inheritance allows one class to acquire properties and methods of another class.

    * Types:

      * Single Inheritance
      * Multilevel Inheritance
      * Hierarchical Inheritance

  * Java does not support multiple inheritance using classes.

Example:
```java
class Animal {
   void eat() {}
}

class Dog extends Animal {
   void bark() {}
}
```

---

4. Explain polymorphism with examples.

  * Polymorphism means “many forms”.

    * Types:

      * Compile-time polymorphism → Method Overloading
      * Runtime polymorphism → Method Overriding

Example:
```java
class Animal {
   void sound() {
      System.out.println("Animal sound");
   }
}

class Dog extends Animal {
   void sound() {
      System.out.println("Dog barks");
   }
}
```

---

5. Differentiate method overloading and method overriding.

| Overloading                                | Overriding                            |
| ------------------------------------------ | ------------------------------------- |
| Same method name with different parameters | Same method in parent and child class |
| Compile-time polymorphism                  | Runtime polymorphism                  |
| Same class                                 | Different classes                     |

---

6. What is encapsulation? How is it implemented?

  * Encapsulation means hiding data using private variables and providing controlled access through getters/setters.

Example:
```java
class Employee {
   private int salary;

   public void setSalary(int salary) {
      this.salary = salary;
   }

   public int getSalary() {
      return salary;
   }
}
```

---

7. What is abstraction? How do abstract classes and interfaces help achieve it?

  * Abstraction hides implementation details and shows only functionality.

    * Abstract Class: Can contain abstract and non-abstract methods.

    * Interface: Contains fully abstract methods (before Java 8).

Example:

```java
abstract class Vehicle {
   abstract void start();
}
```

---

8. Difference between abstract class and interface.

| Abstract Class            | Interface               |
| ------------------------- | ----------------------- |
| Can have concrete methods | Mostly abstract methods |
| Supports constructors     | No constructors         |
| Single inheritance        | Multiple inheritance    |
| Uses `extends`            | Uses `implements`       |

---

9. Can Java support multiple inheritance? How?

  * Java does not support multiple inheritance through classes because of ambiguity issues.

  * But Java supports multiple inheritance using interfaces.

Example:
```java
interface A {}
interface B {}

class C implements A, B {}
```

---

10. What is the purpose of constructors in Java?

  * Constructors initialize objects when they are created.

Example:
```java
class Student {
   Student() {
      System.out.println("Constructor called");
   }
}
```

11. Difference between default and parameterized constructors.

| Default Constructor     | Parameterized Constructor |
| ----------------------- | ------------------------- |
| No parameters           | Accepts parameters        |

Example:
```java
Student() {}

Student(int id) {}
```

12. Are constructors inherited?

  * No, constructors are not inherited because they belong to the specific class itself.

14. What is the purpose of the super keyword?

  * `super` refers to parent class object.

  * Uses:

    * Call parent constructor
    * Access parent methods
    * Access parent variables

Example:
```java
super.display();
```

15. Explain static keyword, static methods, and static variables.

  * Static Variable: Shared among all objects.

  * Static Method: Can be called without object creation.

Example:
```java
class Test {
   static int count = 0;

   static void show() {
      System.out.println("Static method");
   }
}
```

16. Explain final, finally, and finalize.

| Keyword  | Purpose                               |
| -------- | ------------------------------------- |
| final    | Prevents inheritance/modification     |
| finally  | Executes always in exception handling |
| finalize | Called before garbage collection      |

---

17. What is method hiding?

  * If child class defines static method with same name as parent static method, it is called method hiding.

Example:
```java
class A {
   static void show() {}
}

class B extends A {
   static void show() {}
}
```

---

18. What is the purpose of volatile and transient keywords?

  * volatile: Ensures variable value is updated across threads.

  * transient: Prevents variable from serialization.

---

19. Explain serialization and deserialization.

  * Deserialization: Converting byte stream back into object.

  * Used in:

    * File storage
    * Network transfer

21. What is String immutability and String Constant Pool?

  * String Immutability: String objects cannot be modified after creation. Original string remains unchanged.

Example:
```java
String s = "Hello";

```

  * String Constant Pool: Memory area where string literals are stored and reused.

25. Explain checked and unchecked exceptions.

  * Checked Exceptions: Checked during compile time.

Example:
  * IOException
  * SQLException

  * Unchecked Exceptions: Occur during runtime.

Example:

  * NullPointerException
  * ArithmeticException

29. What is Singleton Design Pattern?

  * Singleton ensures only one object instance exists throughout application.

Example: WebDriver manager in automation framework.

```java
class Singleton {
   private static Singleton obj = new Singleton();

   private Singleton() {}

   public static Singleton getInstance() {
      return obj;
   }
}
```
