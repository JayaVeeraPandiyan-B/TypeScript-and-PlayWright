
# Excel / File / Data Handling – Interview Answers

**1. How do you read and write Excel files using Java?**

* In Java, Excel files are commonly handled using the Apache POI library.

* Reading Excel File:

  * Create a `FileInputStream`
  * Open Workbook
  * Access Sheet, Row, and Cell
  * Read data using cell methods

* Writing Excel File:

  * Create Workbook and Sheet
  * Create Rows and Cells
  * Set values
  * Write using `FileOutputStream`

* Example:

```java
import java.io.*;
import org.apache.poi.xssf.usermodel.*;

public class ExcelReadWrite {

    public static void main(String[] args) throws Exception {

        // Reading Excel
        FileInputStream fis = new FileInputStream("TestData.xlsx");
        XSSFWorkbook workbook = new XSSFWorkbook(fis);
        XSSFSheet sheet = workbook.getSheet("Sheet1");

        String value = sheet.getRow(0).getCell(0).getStringCellValue();
        System.out.println(value);

        // Writing Excel
        sheet.getRow(1).createCell(1).setCellValue("PASS");

        FileOutputStream fos = new FileOutputStream("TestData.xlsx");
        workbook.write(fos);

        workbook.close();
        fis.close();
        fos.close();
    }
}
```

* Interview Explanation: “In automation frameworks, we use Apache POI to read test data from Excel sheets and write execution results back into the Excel file.”

**2. Which APIs/libraries are used for Excel operations?**

* The most commonly used libraries are:

* 1. Apache POI

  * Most popular library
  * Supports `.xls` and `.xlsx`
  * Used in Selenium frameworks

* 2. JXL (Java Excel API)

  * Older library
  * Supports only `.xls`
  * Limited features

* 3. EasyExcel

  * Faster for large files
  * Developed by Alibaba

* Apache POI Classes:

| Class        | Purpose        |
| ------------ | -------------- |
| XSSFWorkbook | Excel workbook |
| XSSFSheet    | Sheet handling |
| Row          | Row handling   |
| Cell         | Cell handling  |

* Interview Answer: “Apache POI is the most commonly used library for Excel handling in automation because it supports both reading and writing Excel files efficiently.”

**3. How do you fetch data from properties files?**

* Properties files are used to store configuration values like:

  * URL
  * Username
  * Password
  * Browser name

* Steps:

  1. Create `.properties` file
  2. Use `Properties` class
  3. Load file using `FileInputStream`
  4. Retrieve values using `getProperty()`

* Example:

* config.properties

```properties
url=https://testsite.com
browser=chrome
username=admin
```

* Java Code

```java
import java.io.FileInputStream;
import java.util.Properties;

public class ReadProperties {

    public static void main(String[] args) throws Exception {

        Properties prop = new Properties();

        FileInputStream fis =
            new FileInputStream("config.properties");

        prop.load(fis);

        System.out.println(prop.getProperty("url"));
        System.out.println(prop.getProperty("browser"));
    }
}
```

* Interview Explanation: “We use properties files to externalize configuration data so that values can be changed without modifying the framework code.”

**4. How do you store and retrieve configuration data?**

* Configuration data is generally stored in:

  * Properties files
  * JSON files
  * YAML files
  * Excel files
  * Database

* Most Common Approach:

  * Using `config.properties`

* Stored Data:

  * Application URL
  * Browser type
  * Environment
  * Timeouts
  * Credentials

* Retrieval Process:

  * Load file
  * Use `Properties` object
  * Fetch values dynamically

* Framework Usage:

```java
String browser = prop.getProperty("browser");
```

* Interview Answer: “In automation frameworks, configuration data is externalized using properties files so the framework becomes reusable and environment-independent.”

**5. How do you manage externalized test data?**

* Externalized test data means storing test data outside the code.

* Common Sources:

  * Excel files
  * CSV files
  * JSON files
  * XML files
  * Database
  * Properties files

*  Advantages:

  * Better maintainability
  * Data-driven testing
  * Reusability
  * Easy updates without code changes

*  Example:

  * Login credentials in Excel
  * Environment configs in properties file
  * API payloads in JSON

*  Framework Approach:

  * Create utility classes
  * Read data dynamically
  * Pass data to test methods

*Interview Answer: “I manage externalized test data using Excel, JSON, and properties files. This helps in implementing data-driven frameworks and avoids hardcoding values inside test scripts.”
