
**1. Basic Linux commands used in automation**

* Common Linux Commands:

| Command         | Purpose                    |
| --------------- | -------------------------- |
| `ls`            | List files and folders     |
| `cd`            | Change directory           |
| `pwd`           | Show current directory     |
| `mkdir`         | Create folder              |
| `touch`         | Create file                |
| `cp`            | Copy files                 |
| `mv`            | Move or rename files       |
| `rm`            | Delete files               |
| `cat`           | View file content          |
| `grep`          | Search text inside files   |
| `find`          | Search files/folders       |
| `chmod`         | Change file permissions    |
| `ps`            | Check running processes    |
| `kill`          | Stop a process             |
| `top`           | Monitor system processes   |
| `tar` / `zip`   | Compress files             |
| `wget` / `curl` | Download files or hit APIs |
| `vi` / `nano`   | Edit files                 |
| `ssh`           | Connect to remote server   |

* Interview Explanation: “In automation projects, Linux commands are mainly used for navigating directories, managing files, checking logs, executing scripts, monitoring processes, and working with CI/CD tools like Jenkins.”

**2. How do you create files using Linux commands?**

* Method 1 — Using `touch`

```bash
touch test.txt
```

* Creates an empty file named `test.txt`.

---

* Method 2 — Using `cat`

```bash
cat > test.txt
```

* After typing content, press:

```bash
CTRL + D
```

---

* Method 3 — Using `echo`

```bash
echo "Hello" > test.txt
```

* Creates file and writes content into it.

---

* Method 4 — Using `vi`

```bash
vi test.txt
```

* Opens editor to create and edit file.

---

* Interview Explanation: “We can create files in Linux using commands like touch, cat, echo, and vi depending on whether we need an empty file or a file with content.”

**3. Why is Linux knowledge important for automation engineers?**

* Interview Answer: “Linux knowledge is very important for automation engineers because most automation environments, CI/CD pipelines, cloud servers, and testing environments run on Linux systems.

* Automation engineers use Linux commands for:

  * Running automation scripts
  * Managing files and logs
  * Configuring Jenkins jobs
  * Monitoring processes
  * Working with Docker and cloud servers
  * Scheduling jobs using cron
  * Troubleshooting failures in test execution

* Good Linux knowledge helps in faster debugging, server handling, and automation maintenance.”

---

* Short Version (2-Line Answer)

* “Most automation and CI/CD environments work on Linux servers. Linux knowledge helps automation engineers execute scripts, manage logs, monitor systems, and troubleshoot issues efficiently.”
