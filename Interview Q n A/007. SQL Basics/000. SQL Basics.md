
# SQL Basics – Interview Answers

**1. Write queries to fetch employee details using WHERE conditions**

* Answer: The `WHERE` clause is used to filter records based on specific conditions.

* Example:

```sql
SELECT * 
FROM Employees
WHERE Department = 'IT';
```

* Multiple Conditions:

```sql
SELECT * 
FROM Employees
WHERE Salary > 50000
AND Department = 'HR';
```

* Interview Explanation: “We use WHERE clause to retrieve only required records from a table based on conditions like department, salary, location, status, etc.”

---

**2. Fetch employees based on department, salary range, hire date, and email pattern**

* Department:

```sql
SELECT * 
FROM Employees
WHERE Department = 'Finance';
```

* Salary Range:

```sql
SELECT * 
FROM Employees
WHERE Salary BETWEEN 40000 AND 80000;
```

* Hire Date:

```sql
SELECT * 
FROM Employees
WHERE HireDate >= '2024-01-01';
```

* Email Pattern:

```sql
SELECT * 
FROM Employees
WHERE Email LIKE '%gmail.com';
```

* Interview Explanation: “BETWEEN is used for ranges, LIKE is used for pattern matching, and conditions can be combined using AND/OR.”

---

**3. Sort records using ORDER BY**

* Answer: `ORDER BY` is used to sort records in ascending or descending order.

* Ascending:

```sql
SELECT * 
FROM Employees
ORDER BY Salary ASC;
```

* Descending:

```sql
SELECT * 
FROM Employees
ORDER BY Salary DESC;
```

* Multiple Columns:

```sql
SELECT * 
FROM Employees
ORDER BY Department, Salary DESC;
```

* Interview Explanation: “ASC is default sorting order. DESC is used for reverse sorting.”

---

**4. Use GROUP BY to calculate count, total salary, and averages**

* Count Employees:

```sql
SELECT Department, COUNT(*) AS EmployeeCount
FROM Employees
GROUP BY Department;
```

* Total Salary:

```sql
SELECT Department, SUM(Salary) AS TotalSalary
FROM Employees
GROUP BY Department;
```

* Average Salary:

```sql
SELECT Department, AVG(Salary) AS AverageSalary
FROM Employees
GROUP BY Department;
```

* Interview Explanation: “GROUP BY groups similar records together so aggregate functions like COUNT, SUM, AVG, MAX, MIN can be applied.”

**5. Fetch top N highest-paid employees**

* Top 5 Employees:

```sql
SELECT TOP 5 *
FROM Employees
ORDER BY Salary DESC;
```

* MySQL Version:

```sql
SELECT *
FROM Employees
ORDER BY Salary DESC
LIMIT 5;
```

* Interview Explanation: “We sort salary in descending order and fetch required top records.”

**6. Fetch second highest and third highest salaries**

* Second Highest Salary:

```sql
SELECT MAX(Salary) AS SecondHighest
FROM Employees
WHERE Salary < (
    SELECT MAX(Salary)
    FROM Employees
);
```

* Third Highest Salary:

```sql
SELECT MAX(Salary) AS ThirdHighest
FROM Employees
WHERE Salary < (
    SELECT MAX(Salary)
    FROM Employees
    WHERE Salary < (
        SELECT MAX(Salary)
        FROM Employees
    )
);
```

* Alternative Using DENSE_RANK:

```sql
SELECT Salary
FROM (
    SELECT Salary,
           DENSE_RANK() OVER(ORDER BY Salary DESC) AS RankNo
    FROM Employees
) A
WHERE RankNo = 2;
```

* Interview Explanation: “DENSE_RANK is preferred in real projects because it handles duplicate salaries properly.”

**7. Fetch duplicate records from tables**

* Answer:

```sql
SELECT Name, COUNT(*) AS CountValue
FROM Employees
GROUP BY Name
HAVING COUNT(*) > 1;
```

* Interview Explanation: “GROUP BY groups duplicate values and HAVING filters grouped results.”

---

**8. Use self-join to fetch employee-manager relationships**

* Answer:

```sql
SELECT E.EmployeeName,
       M.EmployeeName AS ManagerName
FROM Employees E
LEFT JOIN Employees M
ON E.ManagerID = M.EmployeeID;
```

* Interview Explanation: “A self-join joins the same table with itself using aliases.”

---

**9. Fetch employees with same salary or same department/title**

* Same Salary:

```sql
SELECT A.EmployeeName,
       B.EmployeeName,
       A.Salary
FROM Employees A
JOIN Employees B
ON A.Salary = B.Salary
AND A.EmployeeID <> B.EmployeeID;
```

* Same Department:

```sql
SELECT *
FROM Employees
WHERE Department IN (
    SELECT Department
    FROM Employees
    GROUP BY Department
    HAVING COUNT(*) > 1
);
```

* Interview Explanation: “Self-join is commonly used to compare rows within the same table.”

**14. Explain GROUP BY, ORDER BY, and WHERE clauses**

* WHERE

  * Filters rows before grouping.

```sql
SELECT * FROM Employees
WHERE Salary > 50000;
```

* GROUP BY

  * Groups rows for aggregate calculations.

```sql
SELECT Department, COUNT(*)
FROM Employees
GROUP BY Department;
```

* ORDER BY

  * Sorts final output.

```sql
SELECT * FROM Employees
ORDER BY Salary DESC;
```

* Interview Explanation: “Execution order is generally WHERE → GROUP BY → ORDER BY.”

**17. Explain joins and self-joins**

* INNER JOIN

  * Returns matching records.

```sql
SELECT *
FROM Employees E
INNER JOIN Departments D
ON E.DepartmentID = D.DepartmentID;
```

* LEFT JOIN

  * Returns all left table records.

```sql
SELECT *
FROM Employees E
LEFT JOIN Departments D
ON E.DepartmentID = D.DepartmentID;
```

* RIGHT JOIN

  * Returns all right table records.

* FULL JOIN

  * Returns all matching and non-matching records.

* SELF JOIN

  * Joins same table itself.

* Interview Explanation: “Joins combine data from multiple tables based on relationships.”

---

**18. How do you retrieve data dynamically from databases in automation?**

* Answer:

  * We use JDBC connectivity and parameterized queries.

* Example:

```java
String query = "SELECT * FROM Employees WHERE EmployeeID=?";
PreparedStatement ps = con.prepareStatement(query);
ps.setInt(1, empId);
ResultSet rs = ps.executeQuery();
```

* Why PreparedStatement?

  * Dynamic values
  * Prevents SQL Injection
  * Better performance

* Interview Explanation: “We retrieve test data dynamically from database to avoid hardcoding values in automation scripts.”
