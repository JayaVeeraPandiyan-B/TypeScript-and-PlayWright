
# Selenium Grid – Interview Answers

74. What is Selenium Grid?

	* Selenium Grid is a component of Selenium used to execute automation tests on:

		* Multiple browsers
		* Multiple operating systems
		* Multiple machines
		* Parallel execution

	* Main Purpose: Reduce execution time and support cross-browser testing.

	* Example: Run same test simultaneously on:

		* Chrome
		* Firefox
		* Edge

	* Interview Line: “Selenium Grid helps achieve parallel and distributed test execution across different environments.”

---

75. Explain Hub and Node concepts.

	* Hub

		* Central server in Selenium Grid.
		* Receives test requests.
		* Distributes tests to nodes.

	* Only one Hub is usually present.

	* Node

		* Machine connected to Hub.
		* Executes test cases.
		* Can contain different browsers and OS configurations.

	* Architecture Flow: Test Script → Hub → Node → Browser

	* Example

		* Hub → Windows machine
		* Node 1 → Chrome
		* Node 2 → Firefox
		* Node 3 → Edge

	* Interview Line: “Hub manages execution requests, while nodes actually execute tests on browsers.”

---

76. Advantages of Selenium Grid.

	* Advantages

		1. Parallel Execution: Runs multiple tests simultaneously.

		2. Saves Execution Time: Large regression suites execute faster.

		3. Cross-Browser Testing: Tests across different browsers.

		4. Cross-Platform Testing: Supports Windows, Linux, and macOS.

		5. Distributed Execution: Tests can run on remote machines.

		6. Scalable Framework: Easy to add more nodes.

	* Interview Line: “Selenium Grid improves execution speed and supports scalable cross-browser testing.”

---

77. How do you run tests in parallel across browsers using Grid?

	* Steps:

		1. Start Selenium Grid Hub.
		2. Register nodes with Hub.
		3. Configure DesiredCapabilities or browser options.
		4. Use RemoteWebDriver.
		5. Execute tests in parallel using TestNG.

	* Example

```java id="h0t7zk"
WebDriver driver =
new RemoteWebDriver(
new URL("http://localhost:4444"),
new ChromeOptions());
```

	* TestNG Parallel Execution

```xml id="ftc6q9"
<suite name="Suite" parallel="tests">
```

	* Interview Line: “We use RemoteWebDriver with Selenium Grid and TestNG parallel execution to run tests across multiple browsers simultaneously.”
