
# Selenium Mouse, Keyboard & Actions – Interview Answers

**56. Explain Actions class in Selenium.**

* Actions class is used to perform advanced user interactions in Selenium.

* It is mainly used for:

	* Mouse actions
	* Keyboard actions
	* Drag and drop
	* Hover operations
	* Double click
	* Right click

* Why Actions class is needed

* Normal Selenium commands sometimes cannot handle complex UI interactions.

* Create Actions Object

```java id="4g0x3r"
Actions action =
new Actions(driver);
```

* Important Methods

| Method          | Purpose         |
| --------------- | --------------- |
| click()         | Click action    |
| doubleClick()   | Double click    |
| contextClick()  | Right click     |
| moveToElement() | Mouse hover     |
| dragAndDrop()   | Drag and drop   |
| sendKeys()      | Keyboard typing |

* Example

```java id="b3u6fd"
Actions action =
new Actions(driver);

action.moveToElement(menu)
.click()
.perform();
```

* **Interview Line:** “We use Actions class for advanced mouse and keyboard interactions that normal Selenium methods cannot handle properly.”

**57. How do you perform right-click, double-click, hover, and keyboard actions?**

* Using Actions class.

* Right Click (Context Click)

```java id="3m5qxl"
Actions action =
new Actions(driver);

action.contextClick(element)
.perform();
```

* Use Case

	* Context menu validation
	* Right-click options testing

* Double Click

```java id="r0j9wv"
action.doubleClick(element)
.perform();
```

* Use Case

	* Open files
	* Trigger special UI actions

* Mouse Hover

```java id="u2t8gn"
action.moveToElement(menu)
.perform();
```

* Use Case

	* Dropdown menus
	* Hidden submenu items

* Keyboard Actions

	* Enter Text

```java id="v4k1sy"
action.sendKeys("Hello")
.perform();
```

	* Press ENTER Key

```java id="1h6dpm"
action.sendKeys(Keys.ENTER)
.perform();
```

	* CTRL + A

```java id="8x2jfr"
action.keyDown(Keys.CONTROL)
.sendKeys("a")
.keyUp(Keys.CONTROL)
.perform();
```

	* TAB Key

```java id="n5p9zu"
action.sendKeys(Keys.TAB)
.perform();
```

* **Interview Line:** “We use Actions class methods with perform() to execute advanced mouse and keyboard operations.”

**58. What is Robot API and where is it used?**

* Robot API is a Java class used to automate operating system level actions.

* Package:

```java id="9t3xlp"
import java.awt.Robot;
```

* Why Robot API is used

	* Selenium cannot directly handle:

		* OS popups
		* File upload dialogs
		* Keyboard shortcuts outside browser

* Robot API helps automate these actions.

* Common Robot API Methods

| Method       | Purpose            |
| ------------ | ------------------ |
| keyPress()   | Press keyboard key |
| keyRelease() | Release key        |
| mouseMove()  | Move mouse         |
| mousePress() | Mouse click        |

* Example – Press ENTER Key

```java id="y7v4dq"
Robot robot = new Robot();

robot.keyPress(KeyEvent.VK_ENTER);
robot.keyRelease(KeyEvent.VK_ENTER);
```

---

* Example – File Upload

	* Steps:

		1. Copy file path.
		2. Open upload popup.
		3. Paste using CTRL + V.
		4. Press ENTER.

```java id="k1m8wh"
StringSelection ss =
new StringSelection("C:\\test.pdf");

Toolkit.getDefaultToolkit()
.getSystemClipboard()
.setContents(ss, null);
```

* **Interview Line:** “Robot API is mainly used for handling OS-level popups and keyboard operations that Selenium cannot control directly.”
