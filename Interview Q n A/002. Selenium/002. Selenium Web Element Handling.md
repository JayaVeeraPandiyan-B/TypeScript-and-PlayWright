
# Selenium Web Element Handling – Interview Answers

# 23. Difference between findElement() and findElements()

| findElement()                              | findElements()                  |
| ------------------------------------------ | ------------------------------- |
| Returns single WebElement                  | Returns List<WebElement>        |
| Used when only one element is expected     | Used for multiple elements      |
| Throws NoSuchElementException if not found | Returns empty list if not found |
| Return type → WebElement                   | Return type → List<WebElement>  |

	* Example

		* findElement():

```java id="a8s7h2"
driver.findElement(By.id("username"));
```

f		* indElements():

```java id="a7d9sk"
driver.findElements(By.tagName("a"));
```

	* Interview Line: “We use findElement for single elements and findElements for collections like dropdown values or links.”

# 24. How do you handle dropdowns using Select class and without Select class?

	* Using Select Class

		* Used for `<select>` HTML tag.

```java id="mx0q3d"
Select dropdown = new Select(driver.findElement(By.id("country")));

dropdown.selectByVisibleText("India");
dropdown.selectByValue("IN");
dropdown.selectByIndex(2);
```

	* Without Select Class

		* Used for custom or dynamic dropdowns.

```java id="y6m2qt"
driver.findElement(By.id("dropdown")).click();

List<WebElement> options =
driver.findElements(By.xpath("//li"));

for(WebElement option : options)
{
    if(option.getText().equals("India"))
    {
        option.click();
        break;
    }
}
```

# 25. How do you select values from dynamic dropdowns?

	* Steps:

		1. Click dropdown.
		2. Capture all options using findElements().
		3. Iterate through list.
		4. Match required value.
		5. Click selected option.

	* Example

```java id="6g1tla"
List<WebElement> cities =
driver.findElements(By.xpath("//li"));

for(WebElement city : cities)
{
    if(city.getText().equals("Chennai"))
    {
        city.click();
        break;
    }
}
```

	* Interview Line: “We usually use looping with findElements for dynamic dropdown handling.”

# 27. How do you fetch text and attribute values from elements?

	* Fetch Text

		* Uses getText()

```java id="u0ypsg"
String text =
driver.findElement(By.id("message")).getText();
```

	* Fetch Attribute Value

		* Uses getAttribute()

```java id="8snhzy"
String value =
driver.findElement(By.id("email"))
.getAttribute("value");
```

	* Interview Line: “getText retrieves visible text, whereas getAttribute retrieves HTML attribute values.”

# 29. How do you handle hidden elements?

	* Methods:

		* JavaScriptExecutor
		* Modify DOM using JS
		* Wait until visible

	* Example using JavaScriptExecutor

```java id="x7p23o"
JavascriptExecutor js =
(JavascriptExecutor) driver;

js.executeScript(
```

	* Interview Line: “If normal Selenium actions fail for hidden elements, we use JavaScriptExecutor.”

# 30. How do you handle dynamic Ajax elements?

	* We use:

		* Explicit Wait
		* ExpectedConditions

	* Example

```java id="h2mz0u"
WebDriverWait wait =
new WebDriverWait(driver,
Duration.ofSeconds(10));

wait.until(ExpectedConditions
.visibilityOfElementLocated(By.id("msg")));
```

	* Interview Line: “For Ajax elements we use explicit waits instead of Thread.sleep.”

# 31. How do you perform drag-and-drop operations?

	* Using Actions class.

```java id="vlm3ix"
Actions action =
new Actions(driver);

action.dragAndDrop(source, target)
.perform();
```

	* Alternative:

```java id="4qepiq"
action.clickAndHold(source)
.moveToElement(target)
.release()
.perform();
```

# 35. How do you capture screenshots in Selenium?

	* Using TakesScreenshot interface.

```java id="eq7p4o"
TakesScreenshot ts =
(TakesScreenshot) driver;

File src = ts.getScreenshotAs(
OutputType.FILE);

FileUtils.copyFile(src,
new File("screenshot.png"));
```

	* Uses:

		* Failure analysis
		* Reporting
		* Debugging

# 36. How do you identify broken links and broken images?

	* We:

		1. Capture all links/images.
		2. Get URL using href or src.
		3. Use HttpURLConnection.
		4. Check response code.

	* Example Logic

```java id="r5u8wq"
List<WebElement> links =
driver.findElements(By.tagName("a"));

for(WebElement link : links)
{
    String url =
    link.getAttribute("href");
}
```

	* Common Response Codes

| Code | Meaning      |
| ---- | ------------ |
| 200  | Success      |
| 404  | Not Found    |
| 500  | Server Error |

# Interview Line: “We validate URLs using HTTP response codes to identify broken links and images.”
