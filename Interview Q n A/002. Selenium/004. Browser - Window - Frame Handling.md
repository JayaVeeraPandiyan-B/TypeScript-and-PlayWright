
# Selenium Browser, Window & Frame Handling – Interview Answers

**44. Difference between get() and navigate().to()**

| get()                        | navigate().to()                             |
| ---------------------------- | ------------------------------------------- |
| Loads URL directly           | Navigates to URL                            |
| Waits until page fully loads | Can be used with browser navigation methods |
| Simpler method               | Part of Navigation interface                |

* Example

	* Using get():

```java id="z2t3fh"
driver.get("https://google.com");
```

	* Using navigate().to():

```java id="e4m7pk"
driver.navigate().to("https://google.com");
```

* **Interview Line:** “Both open URLs, but navigate() provides additional browser navigation capabilities like back, forward, and refresh.”

**46. Difference between close() and quit()**

| close()                          | quit()                        |
| -------------------------------- | ----------------------------- |
| Closes current browser window    | Closes all browser windows    |
| Ends current session window only | Ends entire WebDriver session |

* Example

```java id="gn8u7y"
driver.close();
```

```java id="tk3q1m"
driver.quit();
```

* **Interview Line:** “We generally use quit() in framework teardown to close complete browser session.”

**48. How do you handle multiple windows and tabs?**

* Steps:

	1. Capture parent window ID.
	2. Capture all window IDs.
	3. Iterate through windows.
	4. Switch to required window.

* Example

```java id="9sx6fh"
String parent =
driver.getWindowHandle();

Set<String> windows =
driver.getWindowHandles();

for(String window : windows)
{
    driver.switchTo().window(window);
}
```

* **Interview Line:** “We use window handles to switch between parent and child browser windows.”

---

**49. Difference between getWindowHandle() and getWindowHandles()**

| getWindowHandle()        | getWindowHandles()        |
| ------------------------ | ------------------------- |
| Returns single window ID | Returns all window IDs    |
| Return type → String     | Return type → Set<String> |

* Example

	* Single window:

```java id="h0vn5p"
driver.getWindowHandle();
```

	* Multiple windows:

```java id="q8z7ym"
driver.getWindowHandles();
```

**50. How do you switch frames and nested frames?**

* Switch by Index

```java id="4k7xdp"
driver.switchTo().frame(0);
```

* Switch by Name or ID

```java id="0yq2nm"
driver.switchTo().frame("frame1");
```

* Switch by WebElement

```java id="f8j4tr"
WebElement frame =
driver.findElement(By.id("frame1"));

driver.switchTo().frame(frame);
```

* Nested Frames

```java id="d2m9qx"
driver.switchTo().frame("parentFrame");
driver.switchTo().frame("childFrame");
```

* **Interview Line:** “We must switch into frame before interacting with elements inside it.”

**51. How do you switch back to parent frame/window?**

* Parent Frame

```java id="3xv8ok"
driver.switchTo().parentFrame();
```

* Main Page

```java id="m9f5ts"
driver.switchTo().defaultContent();
```

* Parent Window

```java id="p1u3hj"
driver.switchTo().window(parentWindowID);
```

* **Interview Line:** “defaultContent() switches control back to main webpage from frames.”

**52. How do you handle browser notifications and permission popups?**

* Using browser options.

	* Chrome Notification Disable

```java id="9d5mvl"
ChromeOptions options =
new ChromeOptions();

options.addArguments(
"--disable-notifications");

WebDriver driver =
new ChromeDriver(options);
```

* Permission Popups

	* Camera access
	* Microphone access
	* Location access

* Handled through browser preferences.

* **Interview Line:** “We disable browser notifications using browser options before launching browser.”

**54. How do you handle SSL certificate issues and HTTPS websites?**

* Using browser options to ignore certificate errors.

	* Chrome Example

```java id="l6u3pr"
ChromeOptions options =
new ChromeOptions();

options.setAcceptInsecureCerts(true);

WebDriver driver =
new ChromeDriver(options);
```

* **Interview Line:** “We configure browser capabilities to accept insecure certificates during testing.”

**55. How do you disable/delete cookies?**

* Delete Specific Cookie

```java id="j7r2ka"
driver.manage().deleteCookieNamed("test");
```

* Delete All Cookies

```java id="p8m4xu"
driver.manage().deleteAllCookies();
```

* Add Cookie

```java id="k2f7vl"
Cookie cookie =
new Cookie("user","admin");

driver.manage().addCookie(cookie);
```

* **Interview Line:** “We clear cookies mainly to avoid session issues and ensure clean test execution.”
