
# Selenium Basics – Interview Answers

**1. What is Selenium?**

* Selenium is an open-source automation testing tool used to automate web applications across different browsers.

* It is mainly used for:

	* Functional Testing
	* Regression Testing
	* Cross-browser Testing

* Example: We can automate login functionality of a website using Selenium.

---

**2. Explain Selenium architecture and Selenium components.**

* Selenium architecture mainly contains these components:

	1. Selenium IDE

		* Record and playback tool.
		* Used for simple automation.
		* No programming knowledge required.

	2. Selenium RC (Remote Control)

		* Old Selenium tool.
		* Used JavaScript injection for automation.
		* Now deprecated.

	3. Selenium WebDriver

		* Directly communicates with browser drivers.
		* Faster and more stable than RC.
		* Supports real browser automation.

	4. Selenium Grid

		* Used for parallel execution.
		* Runs tests on multiple browsers and machines simultaneously.

* Simple Architecture Flow

	* Test Script → WebDriver API → Browser Driver → Browser

	* Example: Java Script → ChromeDriver → Chrome Browser

---

**3. Difference between Selenium RC, IDE, Grid, and WebDriver.**

| Component          | Purpose             | Advantage              | Limitation       |
| ------------------ | ------------------- | ---------------------- | ---------------- |
| Selenium IDE       | Record and playback | Easy to use            | Limited features |
| Selenium RC        | Old automation tool | Supported old browsers | Slow             |
| Selenium WebDriver | Browser automation  | Fast and reliable      | Only web apps    |
| Selenium Grid      | Parallel execution  | Saves execution time   | Setup is complex |

---

**4. Advantages and limitations of Selenium.**

* Advantages

	* Open-source and free.
	* Supports multiple browsers.
	* Supports multiple programming languages.
	* Cross-platform support.
	* Easy integration with frameworks like TestNG and Maven.

* Limitations

	* Cannot automate desktop applications directly.
	* No built-in reporting.
	* No built-in object repository.
	* Cannot automate CAPTCHA easily.
	* Requires coding knowledge.

	* Functional Testing
	* Regression Testing
	* Smoke Testing
	* Sanity Testing
	* Cross-browser Testing
	* End-to-End Testing

**7. Can Selenium be integrated with API testing tools?**

* Yes, Selenium can be integrated with API testing tools like:

	* Rest Assured
	* Postman
	* Apache HttpClient

* Why integration is useful:

	* Validate backend APIs before UI testing.
	* Faster validation.
	* End-to-End workflow testing.

* Example:

	1. Create user using API.
	2. Login using Selenium UI automation.
	3. Verify user details on webpage.

---

**8. What is WebDriver? Is it an interface or class?**

* Selenium WebDriver is an interface in Selenium used to automate browsers.

* It contains methods like:

	* get()
	* findElement()
	* click()
	* quit()

* Browser-specific classes implement this interface.

* Example:

	* ChromeDriver
	* FirefoxDriver
	* EdgeDriver

---

**9. Explain the statement: WebDriver driver = new ChromeDriver().**

```java
WebDriver driver = new ChromeDriver();
```

* Explanation

	* WebDriver → Interface reference variable
	* driver → Reference variable name
	* new ChromeDriver() → Creates Chrome browser object

* Why this is used - This follows Runtime Polymorphism in Java.

	* Because of interface reference: We can switch browsers easily.

* Example:

```java
WebDriver driver = new FirefoxDriver();
```

* Only one line changes.

---

**10. Why create reference variables using WebDriver interface?**

* Using WebDriver interface provides:

	* Flexibility
	* Reusability
	* Runtime Polymorphism

* Example:

```java
WebDriver driver;
```

	* Can later assign:

```java
driver = new ChromeDriver();
driver = new FirefoxDriver();
driver = new EdgeDriver();
```

* Benefits:

	* Easy browser switching
	* Better framework design
	* Loose coupling

* Interview Line: “We use WebDriver interface reference because it supports runtime polymorphism and allows cross-browser execution easily.”
