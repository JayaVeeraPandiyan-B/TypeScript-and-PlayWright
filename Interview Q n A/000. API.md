1. What is an API?
  * An API allows two applications to communicate with each other.

    Example: A mobile app fetches user data from a server.

2. What is REST API?
  * A REST API uses HTTP methods to perform operations on resources.

    Example: GET /users returns a list of users.
    
3. What is the difference between REST and SOAP?
  * REST is lightweight and uses JSON, while SOAP is heavier and uses XML.

    Example: REST APIs are commonly used in web apps, SOAP in enterprise systems.

4. What are HTTP methods?
  * HTTP methods define the type of operation to perform on a resource.

    Example: GET (read), POST (create), PUT (update), DELETE (remove).

5. What is the difference between GET and POST?
  * GET retrieves data, while POST sends data to create a resource.

    Example: GET /users vs POST /users with request body.

6. What is the difference between PUT and PATCH?
  * PUT updates the entire resource, while PATCH updates only specific fields.

    Example: PATCH updates only email instead of full profile.

7. What is DELETE method used for?
  * DELETE removes a resource from the server.

    Example: DELETE /users/1

8. What is an endpoint?
  * An endpoint is a specific API URL used to access a resource.

    Example: /users/1

9. What is base URL?
  * The base URL is the root address of an API.

    Example: https://api.example.com

10. What is JSON?
  * JSON is a lightweight data format used for API communication.

    Example: { "name": "John", "age": 30 }

# ********** HTTP & Status Codes **********

12. What are HTTP status codes?
  * They indicate the result of an API request.

    Example: 200 means success. 

13. Explain 200, 201, 204 status codes.
  * 200 = success, 201 = resource created, 204 = success with no content.

    Example: POST returns 201 after creating a user.

14. What is 400 Bad Request?
  * The request is invalid or malformed.

    Example: Missing required field in request body.

15. What is 401 vs 403?
  * 401 means unauthenticated, 403 means unauthorized.

    Example: Invalid token (401), no access rights (403).

16. What is 404 error?
  * Resource not found on the server.

    Example: /users/999 not existing.

17. What is 500 Internal Server Error?
  * Server failed to process the request.

    Example: Backend crash.

18. What is the difference between 502 and 503?
  * 502 = bad gateway, 503 = service unavailable.

    Example: Server down returns 503.

# ********** Authentication & Security **********
20. What is authentication vs authorization?
  * Authentication verifies identity, authorization checks permissions.

    Example: Login vs access admin page.

21. What is Basic Authentication?
  * Uses username and password in request header.

    Example: Base64 encoded credentials.

22. What is Bearer Token?
  * A token used in headers to access APIs securely.

    Example: Authorization: Bearer abc123

23. What is OAuth 2.0?
  * A secure authorization framework using tokens.

    Example: Login with Google.

24. What is JWT?
  * A token format containing user data and signature.

    Example: Used for stateless authentication.

25. What is API key?
  * A unique key used to authenticate API requests.

    Example: x-api-key: 12345

27. How do you secure an API?
  * APIs are secured using HTTPS, tokens, and validation.

    Example: Use JWT and rate limiting.

# ********** API Testing **********

27. What is API testing?
  * Testing APIs without UI to validate functionality and performance.

    Example: Verify response of login API.

28. What are validations you perform in API testing?
  * Check status code, response body, headers, and response time.

    Example: Validate 200 and correct JSON.

29. How do you test negative scenarios?
  * Testing APIs with invalid inputs to check error handling.

    Example: Invalid email format.

30. What is schema validation?
  * Validating response structure against expected schema.

    Example: Required fields exist.

31. What is contract testing?
  * Ensures API matches agreed structure between systems.

    Example: Frontend expects specific JSON.

32. How do you test response time?
  * Validates how fast an API responds.

    Example: Response < 2 seconds.

33. What is idempotency?
  * Same request gives same result repeatedly.

    Example: GET request.

34. How do you handle dynamic values in API testing?
  * Store and reuse values like tokens between requests.

    Example: Save token from login API.

# ********** Tools & Automation **********

35. How do you test API using Postman?
  * A tool to test APIs manually.

    Example: Send GET request.

36. What is collection runner in Postman?
  * Runs multiple API requests in sequence.

    Example: Run all test cases together.

37. How do you run Postman collections in CI/CD?
  * Run API tests automatically in pipelines.

    Example: Jenkins executes tests.

38. What is Newman?
  * CLI tool to run Postman collections.

    Example: Run tests via command line.

39. How do you automate API testing using Rest Assured?
  * Java library for API automation testing.

    Example: Write automated test scripts.

40. How do you validate JSON response in automation?
  * Verify response keys and values programmatically.

    Example: Assert response contains “status”.

41. How do you pass headers in API automation?
  * Headers are sent to provide metadata or auth info.

    Example: Authorization token.

42. How do you handle authentication token in automation?
  * Extract and reuse tokens across API calls.

    Example: Login → get token → use in next API.

# ********** Advanced API Concepts **********

43. What is rate limiting?
  * Limits number of API requests per user.

    Example: 100 requests per minute.

44. What is pagination?
  * Splits large data into smaller pages.

    Example: page=1

45. What is caching?
  * Stores responses to improve performance.

    Example: Reusing previous response.

46. What is CORS?
  * Controls access from different domains.

    Example: Browser blocking cross-origin requests.

47. What is throttling?
  * Controls API usage rate dynamically.

    Example: Slowing excessive requests.

48. What is mocking in API testing?
  * Creating fake APIs for testing.

    Example: Test without real backend.

49. What is Swagger/OpenAPI?
  * Tools for API documentation and testing.

    Example: View API endpoints in UI.

50. What is microservices architecture?
  * Application divided into small independent services.

    Example: Separate user and payment services.

51. What is versioning in API?
  * Managing different versions of APIs.

    Example: /v1/users

52. What are best practices for REST API d
  * Use proper methods, status codes, and security.

    Example: Use HTTPS and meaningful responses.
