
# Rest Assured & API Automation — Interview Answers

**1. What is Rest Assured?**

* REST Assured is a Java library used for automating REST API testing.

  * It helps:

    * Send HTTP requests
    * Validate API responses
    * Perform schema validation
    * Automate end-to-end API testing

  * Supports:

    * GET
    * POST
    * PUT
    * PATCH
    * DELETE

  * Advantages:

    * Easy syntax
    * Supports JSON/XML
    * Integrates with TestNG/JUnit
    * Supports BDD style testing

---

**2. Explain RequestSpecification and ResponseSpecification in Rest Assured.**

* RequestSpecification: Used to define reusable request configurations.

  * Includes:

    * Base URI
    * Headers
    * Authentication
    * Query parameters

  * Example:

```java id="ozw8y9"
RequestSpecification request =
given()
.baseUri("https://api.company.com")
.header("Content-Type","application/json");
```

  * Benefits:

    * Reusability
    * Reduced code duplication

---

* ResponseSpecification: Used to define reusable response validations.

  * Includes:

    * Status code
    * Response time
    * Headers

  * Example:

```java id="5r9nzc"
ResponseSpecification responseSpec =
expect()
.statusCode(200);
```

---

**3. Explain POJO usage in API automation.**

* POJO stands for Plain Old Java Object.

  * Used to:

    * Represent request payloads
    * Represent response bodies

  * Benefits:

    * Cleaner code
    * Easy serialization/deserialization
    * Better maintainability

  * Example:

```java id="7v8yl0"
public class User {
   private String name;
   private int age;
}
```

* POJO objects can be automatically converted into JSON.

---

**4. How do you create POST requests using JSON payloads?**

* Example using Rest Assured:

```java id="k80fw6"
given()
.header("Content-Type","application/json")
.body("{\"name\":\"John\"}")
.when()
.post("/users")
.then()
.statusCode(201);
```

* Steps:

  * Set headers
  * Add request body
  * Send POST request
  * Validate response

---

**5. How do you validate JSON schema programmatically?**

* Using JSON schema validation in Rest Assured:

```java id="jv40x8"
given()
.when()
.get("/users")
.then()
.assertThat()
.body(matchesJsonSchemaInClasspath("schema.json"));
```

* Validations include:

  * Data types
  * Mandatory fields
  * Structure validation

* Benefits:

  * Prevent schema mismatch
  * Ensure API contract consistency

**7. How do you pass headers in API automation?**

* Headers are passed using `.header()` method.

  * Example:

```java id="4s4p9r"
given()
.header("Authorization","Bearer token")
.header("Content-Type","application/json")
.when()
.get("/users");
```

  * Common headers:

    * Authorization
    * Content-Type
    * Accept

---

**8. How do you handle authentication tokens in automation?**

* Steps:

  * Call authentication API
  * Extract token
  * Store token
  * Pass token in subsequent requests

* Example:

```java id="s5brgq"
String token = response.jsonPath().getString("token");
```

* Use token:

```java id="g8yspg"
.header("Authorization","Bearer " + token)
```

* Benefits:

  * Dynamic authentication
  * Avoid hardcoding

**9. How do you validate JSON responses in automation?**

* Example:

```java id="jln6ho"
given()
.when()
.get("/users/101")
.then()
.statusCode(200)
.body("name", equalTo("John"));
```

* Common validations:

  * Field values
  * Nested objects
  * Array size
  * Null checks

**10. How do you manage dynamic data in API automation frameworks?**

* Dynamic data examples:

  * Tokens

  * Timestamps

* Approach:

  * Extract values from response
  * Store in variables
  * Reuse in next requests

* Example:

```java id="0mf0x2"
int id = response.jsonPath().getInt("id");
```

* Benefits:

  * Better test flow

**11. How do you perform request chaining in Rest Assured?**

* Request chaining means passing response data from one API to another API.

  * Example flow:

    * Create user
    * Extract user ID
    * Update same user

  * Example:

```java id="a9h2v0"
int userId = response.jsonPath().getInt("id");
```

  * Use in next request:

```java id="q7x5wt"
.put("/users/" + userId);
```

**12. How do you implement data-driven API automation?**

* Data-driven testing runs same test with multiple datasets.

  * Data sources:

    * Excel
    * CSV
    * JSON
    * Database

  * Example:

```java id="c5k4n6"
@DataProvider(name="userData")
```

  * Benefits:

    * Better coverage
    * Reduced duplicate scripts
    * Reusable tests

**13. How do you structure an API automation framework?**

* Typical framework structure:

```text id="5b4sc5"
src/test/java
 ├── tests
 ├── utils
 ├── payloads
 ├── base
 ├── config
 ├── reports
 └── resources
```

* Components

  * Base Class: Common setup configuration.

  * Test Classes: Contains API test cases.

  * Utility Classes: Reusable helper methods.

  * Payload Classes: JSON payload builders or POJOs.

  * Config Files: Environment URLs and credentials.

  * Reporting: Extent Reports / Allure Reports.

  * CI/CD Integration: Jenkins or GitHub Actions execution.

* Framework Features:

  * Reusability
  * Scalability
  * Maintainability
  * Reporting support
