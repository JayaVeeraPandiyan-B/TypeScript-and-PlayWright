
# Playwright Locators & Assertions – Interview Answers

**11. Explain Locators in Playwright**

* Locators are used to identify and interact with web elements in Playwright.

* They help perform actions like:

	* click
	* type
	* hover
	* validate elements

* Playwright locators automatically wait for elements to become visible and stable before performing actions.

**Example:**

```ts id="xzk5qz"
await page.locator('#username').fill('admin');
await page.locator('#loginBtn').click();
```

**Interview Answer:** “Locators in Playwright are used to identify web elements and interact with them. Playwright provides auto-waiting functionality, making locators more stable and reliable compared to traditional selectors.”

---

**12. What Selector Types are Available?**

* Playwright supports multiple selector types:

* CSS Selector

```ts id="e3py8w"
page.locator('#id')
```

* Text Selector

```ts id="ml41bg"
page.locator('text=Login')
```

* XPath Selector

```ts id="qj0s3d"
page.locator('//button')
```

* Role Selector

```ts id="d7jv9t"
page.getByRole('button', { name: 'Login' })
```

* Label Selector

```ts id="nt0kkv"
page.getByLabel('Username')
```

* Placeholder Selector

```ts id="1k8e3h"
page.getByPlaceholder('Enter username')
```

* Test ID Selector

```ts id="e5qv0l"
page.getByTestId('submit-btn')
```

**Interview Answer:** “Playwright supports different selector types like CSS, XPath, text selectors, role-based selectors, label selectors, placeholder selectors, and test IDs. Role-based and test ID selectors are commonly preferred because they improve stability.”

---

**13. Does Playwright Support XPath?**

* Yes. Playwright supports XPath selectors.

**Example:**

```ts id="1o6t9s"
await page.locator('//input[@id="username"]').fill('admin');
```

* But Playwright recommends:

 * CSS selectors
 * Role selectors
 * Test ID selectors

* because they are faster and more reliable.

**Interview Answer:** “Yes, Playwright supports XPath selectors. However, Playwright recommends using role-based or CSS selectors because they are more stable and easier to maintain.”

**14. Explain Assertions, Hard Assertions, and Soft Assertions**

* Assertions are used to validate expected results in tests.

* Hard Assertions: Test stops immediately if assertion fails.

**Example:**

```ts id="7x67mp"
await expect(page).toHaveTitle('Dashboard');
```

* Soft Assertions: Test continues even if assertion fails.

**Example:**

```ts id="7syy7j"
await expect.soft(page).toHaveTitle('Dashboard');
```

**Interview Answer:** “Assertions are used to validate application behavior. In hard assertions, the test execution stops when validation fails. In soft assertions, the test continues execution even if the assertion fails.”

---

**15. How Do You Validate Page Title, URL, and UI Elements?**

* Validate Title

```ts id="14hy7x"
await expect(page).toHaveTitle('Home');
```

* Validate URL

```ts id="20yy7m"
await expect(page).toHaveURL('https://example.com');
```

* Validate Element Visibility

```ts id="s4n7z7"
await expect(page.locator('#loginBtn')).toBeVisible();
```

* Validate Text

```ts id="q2w0wd"
await expect(page.locator('.message')).toHaveText('Success');
```

**Interview Answer:** “In Playwright, validations are done using assertions. We can validate page title using toHaveTitle(), URL using toHaveURL(), and UI elements using methods like toBeVisible() and toHaveText().”
