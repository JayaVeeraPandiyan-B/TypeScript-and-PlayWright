
# Playwright Basics – Interview Answers

1. What is Playwright?

	* Playwright is an open-source automation testing framework developed by Microsoft for web application testing.

	* It supports:

		* Chromium
		* Firefox
		* WebKit

	* It can automate:

		* UI testing
		* API testing
		* End-to-end testing

* Interview Answer: “Playwright is an open-source automation framework used for end-to-end testing of web applications. It supports multiple browsers like Chromium, Firefox, and WebKit, and provides fast and reliable automation with features like auto-waiting, parallel execution, and cross-browser testing.”

---

2. Advantages and Disadvantages of Playwright

	* Advantages

		* Supports multiple browsers
		* Fast execution
		* Auto-wait mechanism
		* Supports parallel execution
		* Supports mobile emulation
		* Built-in screenshots and videos
		* Supports API testing
		* No separate WebDriver required

	* Disadvantages

		* Comparatively newer than Selenium
		* Smaller community support than Selenium
		* Limited support for legacy browsers like IE
		* Requires programming knowledge

* Interview Answer: “Playwright provides faster and more reliable automation with built-in waits, cross-browser support, and parallel execution. It also supports API testing and mobile emulation. One disadvantage is that it is newer compared to Selenium, so community support is relatively smaller.”

---

3. Difference Between Playwright and Selenium

| Playwright                    | Selenium                            |
| ----------------------------- | ----------------------------------- |
| No WebDriver required         | Requires WebDriver                  |
| Faster execution              | Comparatively slower                |
| Built-in auto waits           | Need explicit waits often           |
| Supports modern browsers well | Supports many browsers including IE |
| Supports multiple tabs easily | More complex handling               |
| Better for modern apps        | Widely used in industry             |

* Interview Answer: “The main difference is that Playwright does not require WebDriver, whereas Selenium uses WebDriver for browser communication. Playwright is faster and has built-in auto waiting, while Selenium has wider community support and supports legacy browsers.”

---

4. What Programming Languages are Supported?

	* Playwright supports:

		* JavaScript
		* TypeScript
		* Python
		* Java
		* .NET / C#

* Interview Answer: “Playwright supports multiple programming languages including JavaScript, TypeScript, Python, Java, and .NET. TypeScript and JavaScript are the most commonly used.”

---

5. Does Playwright Require WebDriver?

	* No - Playwright directly communicates with browser engines using its own protocol.

* Interview Answer: “No, Playwright does not require WebDriver. It directly interacts with browser engines, which makes execution faster and more stable.”

---

6. Explain Playwright Architecture

	* Architecture Flow: Test Script → Playwright API → Browser Protocol → Browser

	* Playwright directly communicates with browser engines using:

		* CDP (Chrome DevTools Protocol) for Chromium
		* Native protocols for Firefox and WebKit

* Interview Answer:“Playwright architecture works by directly communicating with browser engines through browser protocols instead of using WebDriver. This direct communication improves speed, stability, and execution performance.”

---

7. How Do You Install and Set Up Playwright?

	* Step 1: Create Project

```bash
npm init -y
```

	* Step 2: Install Playwright

```bash
npm init playwright@latest
```

	* Step 3: Run Test

```bash
npx playwright test
```

* Interview Answer: “To set up Playwright, first create a Node.js project using npm init. Then install Playwright using npm init playwright@latest. After installation, tests can be executed using npx playwright test.”

---

8. Explain Playwright Configuration Files

	* Main configuration file:

```bash
playwright.config.ts
```

	* Used for:

		* Browser setup
		* Base URL
		* Timeouts
		* Parallel execution
		* Reporter settings
		* Retry count

	* Example:

```ts
import { defineConfig } from '@playwright/test';

export default defineConfig({
  timeout: 30000,
  use: {
    browserName: 'chromium',
    headless: true
  }
});
```

* Interview Answer: “The playwright.config.ts file is used to manage Playwright test settings like browser configuration, timeouts, retries, parallel execution, and reporting.”

---

9. What is @playwright/test Package?

	* `@playwright/test` is the official Playwright test runner.

	* It provides:

		* Test execution
		* Assertions
		* Hooks
		* Parallel execution
		* Reporting

* Interview Answer: “@playwright/test is the official testing framework provided by Playwright. It includes test runner features such as assertions, hooks, reporting, retries, and parallel execution.”

---

10. What is Page Class?

	* `Page` represents a single browser tab or webpage.

	* Used for:

		* Navigating URLs
		* Clicking elements
		* Entering text
		* Validating UI

	* Example:

```ts
await page.goto('https://example.com');
await page.click('#login');
```

* Interview Answer: “The Page class in Playwright represents a browser tab. It is used to interact with web elements, perform actions like click and type, and validate application behavior.”
