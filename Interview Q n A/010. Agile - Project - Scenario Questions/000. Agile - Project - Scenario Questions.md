
# AGILE / PROJECT / SCENARIO INTERVIEW ANSWERS

**1. Explain your automation framework architecture.**

* I worked on a Hybrid Automation Framework using Selenium WebDriver, Java, TestNG, Maven, and Jenkins.

* Framework layers include:

  * Page Object Model (POM) for maintaining locators and page actions
  * Test layer for test scenarios
  * Utility layer for reusable methods like waits, screenshots, Excel handling
  * Base class for browser setup and teardown
  * Reporting using Extent Reports
  * Test execution through TestNG XML
  * CI/CD integration using Jenkins
  * Logging using Log4j

* This framework supports:

  * Cross-browser testing
  * Parallel execution
  * Reusable code
  * Data-driven testing
  * Easy maintenance

  * Synchronization issues

* Solutions include:

  * Explicit waits
  * Stable locators
  * Retry mechanisms
  * Better environment validation
  * Improved synchronization logic

---

**12. How do you manage parallel execution safely?**

* We use:

  * ThreadLocal WebDriver

  * Separate browser instances

* This avoids conflicts between parallel threads.

**13. Explain bug reporting and defect tracking process.**

* Bug lifecycle:

  1. Identify issue
  2. Log defect in Jira
  3. Add screenshots/logs
  4. Assign severity and priority
  5. Developer fixes defect
  6. QA retests
  7. Close or reopen defect

* Important defect details:

  * Steps to reproduce
  * Expected vs actual result
  * Environment details
  * Logs/screenshots
