Loop - Oru statement ah 1 or more times nama requirement ku etha maari iterate panalam evlo time venum naalum.

While loop - Oru condition true ah irukura varaikum execute pannum, condition false aana loop stop aagidum.

Do while loop - Loop first oru thadava run aagum, apram condition false aagura varai continue aagum.

For loop - Oru condition true ah irukura varaikum loop execute aagum, condition false aana loop stop aagidum.

    For loop work flow = for(initialization(1); condition(2); increment/decrement(4)) {statements (3)}, So order: 1 → 2 → 3 → 4 → 2 → 3 → 4 → 2 → 3 → 4 → 2...
