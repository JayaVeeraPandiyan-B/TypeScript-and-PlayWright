JavaScript and TypeScript ku 3 key words irukku athu use panni tha Variables la data store pana mudiyum

  * var = In JS & TS modern days la var engayum use pandrathu recommend kedaiyathu - because ithu functional scope, unexpected issues varalam
  * let = Oru variable la irukura value ah change pananum na intha keyword use pananum
  * const = Oru variable la irukura value ah change pana koodathu na ithu use pananum

Inga Syntax: Keyword variableName : data type(Optional) = value;
 Example: var age : number = 30; // data type mention pananum nu avasiyam illa

Intha var, let and Const ku 5 different factors la adangum

* **Scope** - Accessible area (Functional and Block Scope)
  * Function - oru method nu sollalam (Method level) in JS & TS itha function nu solluvom. = "var"
  * Block - function la curly brace inside la irukurathu between open and close. Nested aagavey irunthalum last block ulla irukurathu. = "let" and "Const"

</> Markdown
```ts
function scopeDemo()    {
    var name = "Jaya Veera Pandiyan B";
    let office = "Hexaware";
    console.log("Name:",name); // example of var

    if(true)    {
        let age = 34;
        console.log("Age:",age); // example of let
    }
    //console.log(age); -- let would not come outside of the block
    console.log("Office:",office); // example of var
}
scopeDemo();
```

* **Declaration/Value Assignmen**t - Value illatha variable "Declaration", antha variable ku value assign panita "Initialization"
  * var = ithuku initialize pananum nu avasiyam illa same as "let"
  * let = Variable ethum value initialize panama execute panna "undefined" nu tha print aagum
  * const = kandippa value initialize pananum apdi illana compile time error varum athayum meeri run panana runtime error ah "triggerUncaughtException()" varum athavathu (The Constant "variableName" must be initialized) nu varum.

</> Markdown
```ts
var a = 10
var a = 20
//console.log(a) // example of redeclaration and Initialization
```

* **Re-declaration** - oru variable erkanave declare/initialize panni irunthalum same variable ku another value initialize panalam, ethu recent oh athu final ah eduthukum Example: var city = "Chennai"; var city = "Kovai"; ithula second ah kudutha Kovai la final panikum.

  * Allowed keywords = "var" only.
 
</> Markdown
```ts
let b = 30
let b = 40 //example of redeclare it is not possible in let
console.log(b)
```

* **Re-initialization/Re-assignment** - Erkanavey value assign aagi irukura oru variable ku again vera value assign pandrathu

  * Allowed keywords = "var" and "let" only

* **Hoisting** - Oru variable irukku atha declare um panala initialize um panala but access pana try panna terminal la
  * "undefined" nu varum "var" keyword use panna athavathu ethum declare panathathunaala ipdi sollum terminal la
  * "Cannot access 'variableName' before initialization" nu error varum let and const ku
 
  var Hoisted with "undefined" and let and const (Not initialized)

</> Markdown
```ts
console.log("var:",d,"let:",c) // example of Hoisting ,c
var d;
let c;
const e; //example of for "const" we must initialize
```

**Note:**  Global variable ethavathu block or function ku use aagi mudinja aparam latest value tha print aagum example "let num : number" ipo ithu "undefined" ithu oru for loop block ulla poitu  varuthu antha for loop la 1 to 5 incremental statement iruku na 5 condition false aagura varaikum value increase panitu num ku 6 nu assign aagidum apo ithu tha final value.

</> Markdown
```ts
let num : number;

console.log("Now Global variable 'num' value is:",num);

for  (num = 1; num <= 5; num++)
{
console.log("Inside loop now -",num)
}

console.log("This is outside of the loop, final value of 'num' variable is -",num);

// **********

let num : number;

for(let num:number = 1; num <= 5; num++)
{
console.log("'num' variable declared inside the for loop block -",num)
};

console.log("Now Global variable value is -",num);
console.log("Because 'num' variable not went through inside for loop block");
```
